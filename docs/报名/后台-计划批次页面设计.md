# 后台 — 计划批次页面设计（方案 A）

## 入口

```
左侧菜单: 认证管理

    → 点击某认证行 → 认证详情页
```

## 批次状态与操作

| 状态 | 可操作 | 不可操作 |
|------|--------|---------|
| `draft` | 编辑、发布、删除 | 前端不可见 |
| `published` | 查看订单列表、归档、取消 | 编辑、删除 |
| `archived` | 查看详情、查看历史订单 | 编辑、发布、取消 |

### 操作说明

| 操作 | 触发条件 | 效果 |
|------|---------|------|
| 发布 | draft | 状态 → published，用户端可见 |
| 归档 | published | 状态 → archived，不再接受报名 |
| 取消 | published | 状态 → cancelled，已报名订单标记 closed |
| 删除 | draft | 物理删除 |

## API

全部挂载在认证路由下：

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/admin/certifications/{code}/plans` | 该认证下的批次列表 |
| `POST` | `/admin/certifications/{code}/plans` | 创建批次（draft） |
| `PUT` | `/admin/certifications/{code}/plans/{id}` | 编辑批次（仅 draft） |
| `PUT` | `/admin/certifications/{code}/plans/{id}/publish` | 发布批次 |
| `PUT` | `/admin/certifications/{code}/plans/{id}/archive` | 归档批次 |
| `DELETE` | `/admin/certifications/{code}/plans/{id}` | 删除批次（仅 draft） |

```json

      "capacity": 50,
      "enrolled": 3,
      "status": "published",
      "created_at": "2026-05-15T10:00:00+08:00"

```

| 字段 | 说明 |
|------|------|
| `capacity` | 总名额 |
| `enrolled` | 已报名人数（已支付订单数） |
| `status` | draft / published / archived / cancelled |

## 状态流转图

```
                     ┌──────────┐
            ┌─────── │  draft   │
            │        └────┬─────┘
        [删除]       [发布]
            │            ▼
            │       ┌──────────┐
            │       │published │──── [取消] ──→  cancelled
            │       └────┬─────┘
            │        [归档]
            │            ▼
            │       ┌──────────┐
            └──────→│  删除    │    archived 只能查看
                    └──────────┘
```

## 校验规则

| 规则 | 时机 |
|------|------|
| `apply_start < apply_end` | 创建/编辑 |
| 同一认证下批次名称不重复 | 创建/编辑 |
| `exam_date >= apply_end`（如果有） | 创建/编辑 |
| 仅 draft 可编辑/删除 | 操作前 |
| 仅 draft 可发布 | 发布前 |
| 仅 published 可归档 | 归档前 |

## 与订单的联动

- 发布后 → 用户端列表可见，可创建订单
- 归档后 → 不再接受新订单，已支付订单可继续审核
- 取消后 → 批量关闭该批次下所有未支付订单，已支付订单标记为可退款
