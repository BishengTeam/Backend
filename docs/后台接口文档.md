# 后台接口文档

> 更新日期：2026-05-28
> 管理后台 API，与 C 端小程序 API 在同一 FastAPI 应用中，共享 DB/Redis，认证独立。
> admin 角色：`super_admin` | `content_editor` | `customer_service` | `finance` | `auditor`
> 全部接口需携带 `Authorization: Bearer <admin_jwt>` 请求头（登录接口除外）。

## 管理后台认证

### POST /admin/auth/login — 账号密码登录

#### 请求头

| Header | 值 | 必填 | 说明 |
|--------|------|------|------|
| Content-Type | application/json | 是 | |

#### 路径参数

无

#### 查询参数

无

#### 请求体

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| username | string | 是 | — | 管理员用户名，1-64 字符 |
| password | string | 是 | — | 管理员密码，1-128 字符 |

示例：

```json
{
  "username": "admin",
  "password": "password123"
}
```

#### 响应体

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 |
| message | string | ok |
| data.access_token | string | JWT（type=admin，含 role） |
| data.expires_in | int | access_token 有效时长，单位秒 |
| data.admin.id | int | 管理员 ID |
| data.admin.username | string | 管理员用户名 |
| data.admin.role | string | 角色 |

示例：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "access_token": "eyJhbGciOiJIUzI1NiIs...",
    "expires_in": 7200,
    "admin": {
      "id": 1,
      "username": "admin",
      "role": "super_admin"
    }
  }
}
```

#### 错误码

| code | 说明 |
|------|------|
| 40001 | 参数校验失败（username 或 password 缺失） |
| 40100 | 用户名或密码错误 |
| 50000 | 服务器内部错误 |

#### 示例

```bash
curl -X POST "https://api.example.com/admin/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"username": "admin", "password": "password123"}'
```

## 审核管理

### POST /admin/reviews — 提交审核

#### 请求头

| Header | 值 | 必填 | 说明 |
|--------|------|------|------|
| Authorization | Bearer \<admin_jwt\> | 是 | 管理员 Token |
| Content-Type | application/json | 是 | |

#### 路径参数

无

#### 查询参数

无

#### 请求体

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| target_type | string | 是 | — | 审核对象类型：identity / student / enterprise / order |
| target_id | int | 是 | — | 审核对象 ID（user_id 或 order_id） |
| action | string | 是 | — | 审核动作：approve / reject |
| comment | string\|null | 否 | null | 审核备注，驳回时必填，最长 1024 |

示例：

```json
{
  "target_type": "identity",
  "target_id": 338,
  "action": "approve",
  "comment": null
}
```

#### 响应体

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 |
| message | string | ok |
| data.id | int | 审核记录 ID |
| data.target_type | string | 审核对象类型 |
| data.target_id | int | 审核对象 ID |
| data.action | string | 审核动作 |
| data.comment | string\|null | 审核备注 |
| data.reviewer_id | int | 审核人 ID |
| data.created_at | string | 审核时间，ISO 8601 |

示例：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 1,
    "target_type": "identity",
    "target_id": 338,
    "reviewer_id": 1,
    "action": "approve",
    "comment": null,
    "created_at": "2026-06-19T14:00:00+08:00"
  }
}
```

#### 错误码

| code | 说明 |
|------|------|
| 40001 | 参数校验失败 |
| 40100 | 未登录或 Token 已过期 |
| 40100 | 无管理权限（需 user:write） |
| 40300 | 审核对象不存在 |
| 40200 | 不支持的审核类型 |
| 50000 | 服务器内部错误 |

#### 审核效果

| target_type | action=approve | action=reject |
|-------------|---------------|---------------|
| identity | 实名认证通过，status=verified | 实名驳回，snapshot 恢复，status=rejected |
| student | 学生信息通过，status=verified | 学生驳回，snapshot 恢复，status=rejected |
| enterprise | 企业信息通过，status=verified | 企业驳回，snapshot 恢复，status=rejected |
| order | 订单完成，paid→completed | 退款 + 释放库存，paid→refunded |

#### 示例

```bash
curl -X POST "https://api.example.com/admin/reviews" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..." \
  -H "Content-Type: application/json" \
  -d '{"target_type": "order", "target_id": 170, "action": "approve"}'
```

课程视频和文件不再通过课程创建/编辑请求中的 `video_url` 管理。请使用以下接口：

| 方法 | 路径 | 说明 |
|------|------|------|

| POST | `/admin/courses/{course_id}/assets` | 使用 multipart 上传资源，字段为 `file`、`title`、`asset_type`、`sort_order`、`is_preview` |
| DELETE | `/admin/courses/{course_id}/assets/{asset_id}` | 删除课程资源及其私有文件 |

私有资源播放流程为：先调用 `POST /api/course-assets/{asset_id}/playback-url` 获取两小时有效的签名地址，再使用返回地址访问 `/api/course-assets/{asset_id}/content`。服务端会在签发和实际访问时都校验试看标记或有效学习权限；旧客户端仍可使用带 `Authorization` 的内容接口。

### POST /admin/settings/admins — 创建管理员

| Header | 值 | 必填 | 说明 |
|--------|------|------|------|

无

无

#### 请求体
