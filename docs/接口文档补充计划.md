## 文档格式标准

```python
@router.get("", response_model=APIResponse[PaginatedData[AdminCourseListItem]],
    summary="课程列表",
    description="""
管理后台 **课程管理** 页面使用。

**页面路径**: `/admin/courses`
**使用场景**: 加载课程列表、关键词搜索、分页浏览
**查询参数**:
- `keyword`: 按课程标题模糊搜索
- `category`: 按类目筛选 (basic/primary/intermediate/h3c/sangfor/nisp/renshe)
- `page`: 页码，从 1 开始
- `page_size`: 每页条数，默认 20，最大 100
**响应**: 分页课程数据，含封面、价格、讲师、批次等信息
    """
)
```
