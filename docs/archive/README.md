# 历史文档归档

本目录保存不再作为当前实现依据、但仍有审计或追溯价值的历史材料。

## 使用规则

- 归档内容不得作为当前 API、数据结构、状态机或部署配置的权威来源。
- 当前接口以 `docs/接口列表.md`、领域 OpenAPI 契约和运行时代码为准。
- 当前题库计划以 `docs/quiz/题库模块开发Todo.md` 为准。
- 当前人社 Backend 契约以 `docs/renshe/数据字典与状态机.md` 和 `docs/renshe/接口契约与错误码.md` 为准。
- 归档文件中的外部登录凭据和 API Key 必须删除；历史中曾暴露的密钥需要在对应平台撤销或轮换。

## 目录

- `plan/interface-audit-2026-06/`：2026 年 6 月接口审计计划、分批报告和二审记录。
- `plan/表依赖关系-2026-06.md`：旧版数据库表依赖快照。
- `renshe/patches/`：根目录人社 Todo 的历史同步补丁。
- `references/`：已脱敏的历史外部参考说明。
- `tools/`：不属于 Backend 运行时的历史调研工具，所有密钥均已移除。
