# 人社运行环境与配置矩阵

> 版本：2026-08-10。本文只记录配置边界和验收要求，不保存任何真实凭据。

| 配置面 | 开发 | 测试/预发布 | 生产 |
|---|---|---|---|
| `APP_ENV` | `development` | `test` 或 `staging` | `production` |
| PostgreSQL | 可用本地适配器或独立库 | 独立空库；通过 `TEST_DATABASE_URL` / `TEST_DATABASE_URL_SYNC` 提供 | 独立业务库；应用通过内网主机访问。当前联调约定宿主端口为 `3306`，容器内端口仍以 Compose 服务配置为准 |
| Redis | 可用本地实例 | 独立测试实例 | 内网 `redis://` 或 `rediss://`，不得暴露公网 |
| 人社材料 | `RENSHE_STORAGE_TYPE=local` 仅限本地测试 | 推荐私有阿里云 OSS | 强制 `aliyun_oss` 私有 Bucket；四项 OSS 凭据必填 |
| OSS 签名 | 本地模式不生成公网 URL | 最长 300 秒 | 最长 300 秒；预览、下载和导出分卷均留审计 |
| 微信登录 | 可留空，使用模拟客户端测试 | 使用测试 AppID/Secret | `WECHAT_APPID`、`WECHAT_SECRET` 必填 |
| 微信支付 | 默认关闭；调用支付接口返回配置错误，不提供假成功 | 只有配置 V3 测试商户后才开启 | `WECHAT_PAY_ENABLED=true`；商户号、AppID、商户证书序列号、商户私钥、32 字节 API V3 Key、平台证书、平台证书序列号、支付 HTTPS 通知地址和退款 HTTPS 通知地址全部必填 |
| `RENSHE_CLEANUP_RETENTION_DAYS` | 默认 `30`；可使用大于 `0` 且不超过 `30` 的短周期验证幂等逻辑 | 允许通过部署配置临时缩短，以完成真实 OSS 删除 UAT | 固定 `30`；其他值启动失败，业务 API 和批次页面均不得修改 |
| JWT/PII 密钥 | 使用仅供本机的随机值 | 使用独立随机值 | 由密钥管理系统注入；不得提交仓库或镜像 |
| 日志 | 可调试但不得打印身份证、手机号、令牌或 OSS URL | 与生产相同的脱敏策略 | 结构化采集、轮转、告警；不记录请求体和 Authorization |
| 后台任务 | 支付关闭时不启动支付/退款对账；其他任务可手动运行 | 开启测试商户时至少启动支付对账、退款对账、导出和清理 Worker | 支付对账、退款对账、导出、清理、订单超时 Worker 独立部署和监控，使用 `/ready` 决定切流 |

## 启动校验

生产 Settings 在进程导入时拒绝缺少数据库、Redis、私有 OSS、微信登录或微信支付 V3 配置的实例。配置错误必须让部署失败，不能通过 `alembic stamp` 或“本地退款成功”绕过。

支付和退款通知默认只接受本机时间前后 300 秒内、且匹配当前平台证书序列号的签名。本人主动查单默认每用户每分钟 10 次；支付对账默认每 30 秒扫描 100 笔待支付订单；退款对账默认每 30 秒扫描 100 笔，并主动查询已处理至少 60 秒的退款。对应参数可在安全范围内调整，但两个生产通知地址都必须使用 HTTPS，API V3 Key 必须恰好 32 字节。

## 探针

- `/health` 是存活探针：保留 `checks.database` 和 `checks.redis` 的字符串兼容格式，并返回不含密钥的诊断详情。
- `/ready` 是切流探针：依赖未就绪时返回 HTTP `503`；生产还会对私有 OSS 做只读 Bucket 探针。

## 测试凭据边界

真实 PostgreSQL、OSS、微信登录和微信支付验收必须使用专用测试账号、测试 Bucket 和测试商户，测试数据与生产隔离。缺少凭据时测试应显示 `skipped`/`BLOCKED`，不能把模拟结果记为生产通过。
