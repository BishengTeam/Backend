- 后台内容工作台和旧分类题目列表保留10、20、50、100条/页，新增200、500、1000、1500、2000条/页。仅管理员题目查询接口及其Schema上限提高至2000；个人练习、统计、审计等接口保持原限制。
- 切换题库、模块、知识点或筛选条件时立即回到第一页，不再显示上一范围的题目和勾选。切换每页数量也回到第一页；翻页及切换题库保留已选择的每页数量。
