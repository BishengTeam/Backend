# 生产统一功能配置清单

本文只记录配置项名称、期望口径和检查方式，不记录任何密钥内容。

## 统一启用项

| 模块 | 配置项 | 生产期望 |
| --- | --- | --- |
| 银行转账新订单 | `BANK_TRANSFER_NEW_ORDERS_ENABLED` | `true` |
| 人社私有材料 | `RENSHE_STORAGE_TYPE` | `aliyun_oss` |
| 课程 PDF 上传 | `COURSE_DOCUMENT_UPLOADS_ENABLED` | `true` |
| 人社 OSS 地址 / 桶 | `ALIYUN_OSS_ENDPOINT`, `ALIYUN_OSS_BUCKET` | 必填 |
| 人社 OSS 凭据 | `ALIYUN_OSS_ACCESS_KEY_ID`, `ALIYUN_OSS_ACCESS_KEY_SECRET` | 必填，优先使用 Secret 文件 |
| 题库任务 | `QUIZ_TASKS_ENABLED` | `true` |
| Web 内嵌 Worker | `QUIZ_EMBEDDED_WORKER_ENABLED` | `false` |
| 独立 Worker | `QUIZ_WORKER_PROCESS` | 仅 Worker 容器为 `true` |
| 题库导入存储 | `QUIZ_IMPORT_STORAGE_TYPE` | `aliyun_oss` |
| 题库 OSS 地址 / 桶 | `QUIZ_OSS_ENDPOINT`, `QUIZ_OSS_BUCKET` | 必填 |
| 题库 OSS 凭据 | `QUIZ_OSS_ACCESS_KEY_ID`, `QUIZ_OSS_ACCESS_KEY_SECRET` | 必填，优先使用 Secret 文件 |
| 学习网站桥接地址 | `VIDEOWEB_BASE_URL` | 必填 |
| Backend → 学习网站令牌 | `VIDEOWEB_SERVICE_TOKEN` | 必填；与学习网站 `VIDEOWEB_INTERNAL_SERVICE_TOKEN` 一致 |
| 学习网站 → Backend 令牌 | `VIDEOWEB_LOOKUP_SERVICE_TOKEN` | 必填；与学习网站 `MINIAPP_SERVICE_TOKEN` 一致 |

微信支付 V3、查单、回调与退款配置继续必填。银行转账开关只暂停新现金订单，不应关闭历史微信支付通知、查单和退款能力。

## 学习网站

| 模块 | 配置项 | 生产期望 |
| --- | --- | --- |
| 登录模式 | `MINIAPP_MODE` | `http` |
| 小程序 Backend 地址 | `MINIAPP_BASE_URL` | 必填 |
| 学习网站 → Backend 令牌 | `MINIAPP_SERVICE_TOKEN` | 必填；与 Backend `VIDEOWEB_LOOKUP_SERVICE_TOKEN` 一致 |
| 资源存储 | `STORAGE_MODE` | `aliyun_oss` |
| OSS 地址 / 桶 / 凭据 | `ALIYUN_OSS_ENDPOINT`, `ALIYUN_OSS_BUCKET`, `ALIYUN_OSS_ACCESS_KEY_ID`, `ALIYUN_OSS_ACCESS_KEY_SECRET` | 必填 |
| 数据库 | `VIDEOWEB_DATABASE_URL` | 现有业务 PostgreSQL |

在 API 实际环境中执行：

```bash
python -m app.config_check
```

输出仅包含缺失配置项名称。

## 可选真实服务

| 模块 | 配置项 | 规则 |
| --- | --- | --- |
| AI 咨询 | `CHAT_BACKEND`, `DIFY_API_BASE`, `DIFY_API_KEY` | `CHAT_BACKEND=dify` 时三者必填；未配置时保持禁用 |
| 公众号资讯 | `GZH_APPID`, `GZH_APP_SECRET` | 两者成对配置后启用；未配置时同步任务空转 |
| 实名认证 | 无第三方强制配置 | 继续保留后台人工审核流程 |

## 检查命令

Backend 在实际运行环境中执行：

```bash
python scripts/check_production_features.py
```

命令只输出缺失或无效的配置项名称，不输出地址或密钥内容。

小程序统一使用：

```bash
npm run build:weapp
```

`check:weapp` 会检查 `dist/EDITION` 必须为 `full`，防止误用历史裁剪口径上传。
