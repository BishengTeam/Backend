# 三项目质量命令

## Backend

在 `Backend` 目录执行：

```bash
scripts/quality_gate.sh backend
```

该命令依次执行 Python 编译检查、单元测试、人社 OpenAPI 契约检查和 Alembic 静态检查。单元测试不需要数据库；数据库集成测试必须显式提供独立测试库：

```bash
TEST_DATABASE_URL='postgresql+asyncpg://user:password@host:port/test_db' \
TEST_DATABASE_URL_SYNC='postgresql://user:password@host:port/test_db' \
.venv/bin/python -m pytest tests/integration/db -q
```

空库迁移演练会修改指定测试库，只能对专用测试库执行：

```bash
# 完整升级 -> 降级 -> 再升级
MIGRATION_CHECK_DATABASE_URL='postgresql://user:password@host:port/test_db' \
.venv/bin/python scripts/check_migrations.py --full-cycle
```

`scripts/quality_gate.sh backend` 默认只执行不会连接数据库的迁移图和 offline SQL 检查。

## Admin

在 `Admin` 目录执行：

```bash
npm test
npm run build
```

`npm run build` 同时执行 TypeScript 构建和 Vite 生产构建。

## Platform

在 `Platform` 目录执行：

```bash
npm run build:weapp
```

该命令要求先安装 `package.json` 中的依赖，并生成微信小程序构建产物。

## 全项目

在 `Backend` 目录执行：

```bash
scripts/quality_gate.sh all
```

依赖缺失或命令失败会立即返回非零状态，不会把未执行的项目标记为通过。
