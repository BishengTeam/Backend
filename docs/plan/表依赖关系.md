## 4. 拓扑排序删除顺序

子表先删，父表后删。按批执行，同批内无相互依赖。

```
第 1 批 (17 叶子表 — 仅被引用，不引用其他业务表)
    activity_reminder      → activity, user
    activity_registration  → activity, user
    agreement              → user
    collection             → user
    competition_reg        → user
    conversation           → user
    course_enrollment      → course, user
    deleted_openid         (无 FK)
    job_application        → job, user
    points_history         → user
    quiz_checkin           → user
    quiz_record            → user, quiz_question
    share                  → user
    ticket                 → user
    user_coupon            → user, coupon
    user_identity          → user
    user_points            → user

第 2 批 (解除循环引用 — order ↔ inventory_record)
    inventory_record       → inventory, order

第 3 批 (order — 子表已清理)
    order                  → user, inventory

第 4 批 (父表 — 所有引用方已清理)
    activity
    banner
    coupon
    course
    inventory
    job
    training
    zone

第 5 批 (user — 最终)
    user
```

## 5. 循环引用: `order ↔ inventory_record`

```
order  ──inventory_id──→  inventory
  ↑                         ↑
  └── inventory_record ─────┘ (同时引用 order.id + inventory.id)
```

解除方式: 先删 `inventory_record` (子表)，再删 `order`，最后删 `inventory`。
