# 审核系统开发计划

> 目标：将散落在用户系统和订单系统的审核逻辑抽离，统一为独立的审核模块。
>
> ⚠️ **开发边界**：本次只开发审核模块本身（新增文件），**不修改**用户系统、订单系统的任何代码。旧审核接口保留，与新接口并存。

---

## 1. 数据模型

### 1.1 Review 表

```python
# app/domain/review/src/model/review.py
class Review(Base, TimestampMixin):
    __tablename__ = "review"

    target_type: Mapped[str]   # "identity" | "student" | "enterprise" | "order"
    target_id: Mapped[int]
    reviewer_id: Mapped[int]   # FK admin_user.id
    action: Mapped[str]        # "approve" | "reject"
    comment: Mapped[str | None]
```

不设 `status` 字段 — 审核只做事实记录，不做状态机。

---

## 2. 接口

### 2.1 管理员提交审核

```
POST /admin/reviews
{
    "target_type": "identity" | "student" | "enterprise" | "order",
    "target_id": 123,
    "action": "approve" | "reject",
    "comment": "备注"
}
```

权限：`require_permission("user:write")` 或新增 `review:write`。

### 2.2 查询审核记录

```
GET /admin/reviews?target_type=order&target_id=123
```

按审核对象查历史记录，权限 `review:list`。

## 3. 回调注册表

### 3.1 结构

```python
# app/services/review_callbacks/__init__.py
from collections.abc import Callable, Awaitable

ReviewCallback = Callable[[int, str | None], Awaitable[None]]
# 参数: target_id, comment

REVIEW_CALLBACKS: dict[tuple[str, str], ReviewCallback] = {}
```

### 3.2 各业务注册

```python
# 在模块初始化时注册
from app.services.review_callbacks.identity_callbacks import approve as identity_approve, reject as identity_reject
from app.services.review_callbacks.student_callbacks import approve as student_approve, reject as student_reject
from app.services.review_callbacks.enterprise_callbacks import approve as enterprise_approve, reject as enterprise_reject
from app.services.review_callbacks.order_callbacks import approve as order_approve, reject as order_reject

REVIEW_CALLBACKS[("identity",   "approve")] = identity_approve
REVIEW_CALLBACKS[("identity",   "reject")]  = identity_reject
REVIEW_CALLBACKS[("student",    "approve")] = student_approve
REVIEW_CALLBACKS[("student",    "reject")]  = student_reject
REVIEW_CALLBACKS[("enterprise", "approve")] = enterprise_approve
REVIEW_CALLBACKS[("enterprise", "reject")]  = enterprise_reject
REVIEW_CALLBACKS[("order",      "approve")] = order_approve
REVIEW_CALLBACKS[("order",      "reject")]  = order_reject
```


> 回调实现中需要的业务逻辑（如 `paid → completed` 的状态迁移、snapshot 恢复等），直接 **import 已有的 service 或 domain 方法**，不重复实现。回调文件是薄封装层，调用已有逻辑。`__init__.py` 的导出按需追加，不影响已有导出。
