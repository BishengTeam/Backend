# 在线课程业务开发计划（不含付费/订单）

> 基于 `DOCS/docs/技术/在线课程业务流程.md` 目标流程，**排除订单/支付系统**（由其他人负责），
> 聚焦当前可独立推进的部分。
> 生成日期：2026-06-22

---

## 1. 当前状态 vs 目标

```
目标流程（灰色 = 订单系统，暂不碰）：
                                              ┌─────────────────────────┐
学习专区 → 课程卡片 → 课程详情 → [已购买]  → │ 视频播放页（播放器 + 目录）│
                                              └─────────────────────────┘
                              → [未购买]  →  ……订单+支付……（其他人负责）

当前实际：
学习专区 → 课程卡片 → 课程详情 → [报名] → toast "报名成功" → 留在详情页
我的课程 → [继续学习] → 跳转回课程详情页（不是播放页）
```

| 差距 | 说明 |
|------|------|
| 视频播放页不存在 | `CourseVideo` 组件已开发完，但无页面挂载 |
| 报名后无跳转 | `handleEnroll` 成功后只弹 toast，用户不知道下一步去哪 |
| "我的课程"入口指向错误 | 点击"继续学习"跳到 `/pages/course/detail`，应该跳到播放页 |
| 详情页无状态判断 | 固定显示"报名"按钮，已报名用户看不到"进入学习" |
| 无课程章节目录 | 没有数据模型、API、前端目录列表 |

## 2. 分阶段计划

### 阶段一：打通报名 → 学习闭环（不依赖订单系统）

**目标**：用户报名后能看视频，"我的课程"能点进播放页。

#### 2.1.1 后端：课程详情返回用户报名状态

- **文件**：`Backend/app/schemas/course.py`
- **改动**：`CourseDetailResponse` 新增 `enrollment_status` 字段

```python
EnrollmentStatus = Literal["not_enrolled", "enrolled", "expired"]

class CourseDetailResponse(BaseModel):
    # ... 现有字段保持不变 ...
    enrollment_status: EnrollmentStatus = Field("not_enrolled", description="当前用户对该课程的报名状态")
```

- **文件**：`Backend/app/services/course.py`
- **改动**：`get_course` 方法增加 `user_id` 参数（可选），查询 `CourseEnrollment` 表填充 `enrollment_status`

- **文件**：`Backend/app/api/courses.py`
- **改动**：`get_course` 端点传入当前用户，获取 `current_user` 改为可选（兼容未登录查看）

#### 2.1.2 前端：新建视频播放页

- **文件**：`Platform/src/pages/course/player.tsx`（新建）
- **内容**：
  - 从路由参数获取 `course_id`
  - 调用 `getCourseById(id)` 获取课程详情（拿到 `video_url`）
  - 挂载已有的 `CourseVideo` 组件，将 `video_url` 传入
  - 预留目录列表区域（阶段二填充）

- **路由注册**：`Platform/src/app.config.ts` 新增 `pages/course/player`

#### 2.1.3 前端：课程详情页分支渲染

- **文件**：`Platform/src/pages/course/detail.tsx`
- **改动**：
  - 读取 `enrollment_status` 字段
  - `enrolled` → 底部显示 `进入学习` 按钮，`navigateTo(/pages/course/player?course_id=xxx)`
  - `expired` → 底部显示灰色 `已过期` 提示
  - `not_enrolled` → 保持现有 `报名` 按钮不变

#### 2.1.4 前端：报名成功后跳转

- **文件**：`Platform/src/pages/course/detail.tsx`
- **改动**：`handleEnroll` 成功后 `Taro.navigateTo({ url: '/pages/course/player?course_id=' + courseId })`

#### 2.1.5 前端：修复"我的课程"学习入口

- **文件**：`Platform/src/pages/mine/courses.tsx`
- **改动**：`active` 状态课程卡片点击"继续学习" → 跳转 `/pages/course/player?course_id=xxx`（当前跳的是 `/pages/course/detail`）

### 阶段二：课程目录/章节系统

**目标**：视频播放页有目录列表，点击可切换章节。

#### 2.2.1 数据模型

- **文件**：`Backend/app/domain/certification/src/model/course.py`（新增 `CourseChapter`）

```python
class CourseChapter(Base, TimestampMixin):
    __tablename__ = "course_chapter"

    course_id: Mapped[int] = mapped_column(
        Integer, ForeignKey("course.id", ondelete="CASCADE"), nullable=False, index=True
    )
    title: Mapped[str] = mapped_column(String(256), nullable=False)
    sort_order: Mapped[int] = mapped_column(Integer, default=0)
    video_url: Mapped[str | None] = mapped_column(String(512))
    duration: Mapped[int | None] = mapped_column(Integer)      # 秒
    is_free: Mapped[bool] = mapped_column(default=False)       # 试看

    course: Mapped["Course"] = relationship(back_populates="chapters")
```

同时在 `Course` 模型上加反向关系：
```python
chapters: Mapped[list["CourseChapter"]] = relationship(
    "CourseChapter", back_populates="course", order_by="CourseChapter.sort_order"
)
```

#### 2.2.2 数据库迁移

- **文件**：`Backend/alembic/versions/xxxx_add_course_chapter.py`（新建）
- **操作**：`CREATE TABLE course_chapter`

#### 2.2.3 课程详情接口返回章节

- **文件**：`Backend/app/schemas/course.py`
- **改动**：新增 `ChapterBrief`，`CourseDetailResponse` 加 `chapters: list[ChapterBrief]`

```python
class ChapterBrief(BaseModel):
    id: int
    title: str
    sort_order: int
    video_url: str | None
    duration: int | None
    is_free: bool
    model_config = {"from_attributes": True}
```

- **文件**：`Backend/app/services/course.py`
- **改动**：`get_course` 查询时 `joinedload(Course.chapters)`

#### 2.2.4 Admin 后台章节管理

- **后端 API**：`Backend/app/api/admin/courses.py` 新增子路由

```
GET    /api/admin/courses/{course_id}/chapters      章节列表
POST   /api/admin/courses/{course_id}/chapters      新增章节
PUT    /api/admin/courses/{course_id}/chapters/{id}  编辑章节
DELETE /api/admin/courses/{course_id}/chapters/{id}  删除章节
```

- **后端 Service**：`Backend/app/services/admin_course.py` 新增 `AdminChapterService` 或扩展现有类
- **前端 Admin**：在课程编辑弹窗（`CourseModal.tsx`）内增加章节列表子表，支持拖拽排序、新增/编辑/删除行

#### 2.2.5 前端播放页对接目录

- **文件**：`Platform/src/pages/course/player.tsx`
- **改动**：
  - 左侧/底部渲染章节列表（从 `chapters` 获取）
  - 点击章节切换 `CourseVideo` 的 `videoSrc`
  - 当前播放章节高亮

## 4. 执行建议

1. **阶段一优先**（序号 1-7）：改动量小，效果立竿见影——用户报名后能直接看视频，"我的课程"入口修正。
2. **后端 3 项（1-3）和前端 4 项（4-7）可并行**：接口契约是 `CourseDetailResponse` 新增一个 `enrollment_status` 字段，前端按该字段分支。
3. **阶段二紧随其后**（序号 8-15）：目录系统涉及数据模型变更，需要迁移。8-9 是基础设施必须先做，10-14 可并行，15 最后串联。
4. **阶段三**（序号 16）是锦上添花。

### 阶段一接口契约

**`GET /api/courses/{id}` 响应新增**：
```json
{
  "enrollment_status": "not_enrolled | enrolled | expired"
}
```

**视频播放页入参**：`/pages/course/player?course_id={id}`

**播放页数据来源**：`GET /api/courses/{id}` → `video_url` + 未来 `chapters`

## 5. 注意事项

- `CourseVideo` 组件当前 `videoSrc` 写死为测试地址 `https://vjs.zencdn.net/v/oceans.mp4`，需改为接收外部 prop 或从 `course.video_url` 动态设置。
- 报名状态判断中 `enrollment_status` 来源是 `CourseEnrollment` 表的 `status` 字段（`enrolled`/`completed`/`expired`），不涉及订单表。
- "我的课程"中 `totalLessons`/`completedLessons` 目前硬编码为 0，章节系统上线后可自动计算 `totalLessons`，但学习进度记录需新建 `UserChapterProgress` 表（不在本次范围）。
- 阶段一的后端改动极轻——只需在 `get_course` 方法中加一条 `CourseEnrollment` 查询，不用改数据模型。
