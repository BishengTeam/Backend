## 一、Backend 开发计划

### 前置约束

| 约束 | 说明 |
|------|------|
| 模型位置 | `domain/certification`（与 Course 同域） |
| 接口风格 | 统一 `APIResponse` 包装 |
| 管理端权限 | `course:write` / `course:list` |
| 路由顺序 | `PUT .../chapters/sort` 必须在 `PUT .../chapters/{chapter_id}` 之前注册 |

| 不涉及 | 订单创建、支付、回调、过期关单 |

    __table_args__ = (

### 3. Service 层

#### 3.1 `services/course.py`（CourseService）— 新增方法

```python
class CourseService:

    # --- 现有方法保持不变 ---

    @staticmethod
    async def check_has_access(db, user_id: int, course_id: int) -> bool:
        """唯一入口：判断用户是否有课程学习权限"""
        from app.domain.certification.src.index import CourseEnrollment
        from sqlalchemy import select, and_

        result = await db.execute(
            select(CourseEnrollment).where(
                and_(
                    CourseEnrollment.user_id == user_id,
                    CourseEnrollment.course_id == course_id,
                    CourseEnrollment.learning_access == True,
                )
            )
        )
        return result.scalar_one_or_none() is not None

    async def get_chapters(
        self, course_id: int, user_id: int | None = None
    ) -> dict:
        """返回 { free_preview_seconds, chapters, progress }"""
        from app.domain.certification.src.index import Course, CourseChapter
        from sqlalchemy.orm import joinedload

        async with get_db_ctx() as db:
            course = await db.execute(
                select(Course).options(
                    joinedload(Course.chapters)
                ).where(
                    Course.id == course_id,
                    Course.is_active == True,
                )
            )
            course = course.unique().scalar_one_or_none()
            if course is None:
                raise NotFoundException("课程")

            active_chapters = [
                ch for ch in course.chapters if ch.is_active
            ]
            active_chapters.sort(key=lambda ch: ch.sort_order)

            has_access = (
                await self.check_has_access(db, user_id, course_id)
                if user_id is not None
                else False
            )

            free_seconds = None if has_access else course.free_preview_seconds

            progress = None
            if user_id is not None:
                progress = await self._build_progress(db, user_id, course_id)

            return {
                "free_preview_seconds": free_seconds,
                "chapters": [ChapterResponse.model_validate(ch) for ch in active_chapters],
                "progress": progress,
            }

    async def get_progress(
        self, user_id: int, course_id: int
    ) -> ChapterProgressResponse:
        async with get_db_ctx() as db:
            return await self._build_progress(db, user_id, course_id)

    async def upsert_progress(
        self, user_id: int, course_id: int, data: ChapterProgressUpsert
    ) -> ChapterProgressResponse:
        from app.domain.certification.src.index import CourseChapter
        from sqlalchemy import select

        async with get_db_ctx() as db:
            # 获取章节 duration
            chapter = await db.get(CourseChapter, data.chapter_id)
            if chapter is None or not chapter.is_active:
                raise NotFoundException("章节")

            # 5 秒容差自动判完成
            is_completed = data.is_completed or (
                chapter.duration is not None
                and data.last_position_seconds >= chapter.duration - 5
            )

            stmt = select(UserChapterProgress).where(
                UserChapterProgress.user_id == user_id,
                UserChapterProgress.course_id == course_id,
                UserChapterProgress.chapter_id == data.chapter_id,
            )
            result = await db.execute(stmt)
            progress = result.scalar_one_or_none()

            if progress is None:
                progress = UserChapterProgress(
                    user_id=user_id,
                    course_id=course_id,
                    chapter_id=data.chapter_id,
                    last_position_seconds=data.last_position_seconds,
                    is_completed=is_completed,
                )
                db.add(progress)
            else:
                progress.last_position_seconds = max(
                    progress.last_position_seconds, data.last_position_seconds
                )
                progress.is_completed = progress.is_completed or is_completed

            await db.commit()
            await db.refresh(progress)

            return await self._build_progress(db, user_id, course_id)

    @staticmethod
    async def _build_progress(db, user_id: int, course_id: int):
        """构造 ChapterProgressResponse"""
        from sqlalchemy import select

        rows = (
            await db.execute(
                select(UserChapterProgress).where(
                    UserChapterProgress.user_id == user_id,
                    UserChapterProgress.course_id == course_id,
                ).order_by(UserChapterProgress.updated_at.desc())
            )
        ).scalars().all()

        if not rows:
            return ChapterProgressResponse()

        completed_ids = [r.chapter_id for r in rows if r.is_completed]
        latest = max(rows, key=lambda r: r.updated_at)
        return ChapterProgressResponse(
            last_chapter_id=latest.chapter_id,
            last_position_seconds=latest.last_position_seconds,
            completed_chapter_ids=completed_ids,
        )
```

#### 3.2 `services/admin_course.py`（AdminCourseService）— 新增方法

```python
class AdminCourseService:

    # --- 现有方法保持不变 ---

    async def list_chapters(
        self, course_id: int, is_active: bool | None, page: int, page_size: int
    ) -> PaginatedData[ChapterResponse]:
        async with get_db_ctx() as db:
            base = select(CourseChapter).where(CourseChapter.course_id == course_id)
            if is_active is not None:
                base = base.where(CourseChapter.is_active == is_active)
            count_stmt = select(func.count()).select_from(base.subquery())
            total = (await db.execute(count_stmt)).scalar() or 0
            stmt = (
                base.order_by(CourseChapter.sort_order.asc())
                .offset((page - 1) * page_size)
                .limit(page_size)
            )
            rows = (await db.execute(stmt)).scalars().all()
            return PaginatedData[ChapterResponse](
                items=[ChapterResponse.model_validate(r) for r in rows],
                total=total,
                page=page,
                page_size=page_size,
            )

    async def create_chapter(
        self, course_id: int, data: ChapterCreate
    ) -> ChapterResponse:
        async with get_db_ctx() as db:
            course = await db.get(Course, course_id)
            if course is None:
                raise NotFoundException("课程")
            # sort_order 默认追加到末尾
            if data.sort_order is None:
                max_sort = (
                    await db.execute(
                        select(func.coalesce(func.max(CourseChapter.sort_order), 0))
                        .where(CourseChapter.course_id == course_id)
                    )
                ).scalar() or 0
                sort_order = max_sort + 1
            else:
                sort_order = data.sort_order
            chapter = CourseChapter(
                course_id=course_id,
                title=data.title,
                video_url=data.video_url,
                duration=data.duration,
                sort_order=sort_order,
            )
            db.add(chapter)
            await db.commit()
            await db.refresh(chapter)
            return ChapterResponse.model_validate(chapter)

    async def update_chapter(
        self, chapter_id: int, data: ChapterUpdate
    ) -> ChapterResponse:
        async with get_db_ctx() as db:
            chapter = await db.get(CourseChapter, chapter_id)
            if chapter is None:
                raise NotFoundException("章节")
            update_data = data.model_dump(exclude_unset=True)
            for key, value in update_data.items():
                setattr(chapter, key, value)
            await db.commit()
            await db.refresh(chapter)
            return ChapterResponse.model_validate(chapter)

    async def delete_chapter(self, chapter_id: int) -> None:
        """软删除"""
        async with get_db_ctx() as db:
            chapter = await db.get(CourseChapter, chapter_id)
            if chapter is None:
                raise NotFoundException("章节")
            chapter.is_active = False
            await db.commit()

    async def sort_chapters(
        self, course_id: int, items: list[ChapterSortItem]
    ) -> int:
        """批量更新 sort_order，返回更新条数"""
        async with get_db_ctx() as db:
            count = 0
            for item in items:
                chapter = await db.get(CourseChapter, item.id)
                if chapter is None or chapter.course_id != course_id:
                    continue
                chapter.sort_order = item.sort_order
                count += 1
            await db.commit()
            return count
```

### 5. 用户端接口行为矩阵

#### 章节列表 `GET /api/courses/{course_id}/chapters`

| 用户状态 | `free_preview_seconds` | `chapters` | `progress` |
|----------|------------------------|------------|------------|
| 未登录 | `Course.free_preview_seconds` | 全部 `is_active=True` 的章节 | `null` |
| 已登录，未购买 | 同上 | 同上 | 当前进度 |
| 已登录，已购买 | `null` | 同上 | 当前进度 |

#### 课程详情 `GET /api/courses/{course_id}`

`CourseDetailResponse.chapters` 和 `free_preview_seconds` 填充逻辑与章节列表一致。

#### 进度上报 `POST /api/courses/{course_id}/progress`

- 后端 upsert，`last_position_seconds` 取最大值（不回退）
- `is_completed` 若 `last_position_seconds >= duration - 5`，后端自动置 true
- 返回最新的 `ChapterProgressResponse`

### 3. 视频播放页 — 核心

**路由**：`pages/courses/player?course_id={id}&chapter_id={id}`

**数据来源**：

- `GET /api/courses/{id}/chapters` — 目录 + 试看时长 + 进度
- `POST /api/courses/{id}/progress` — 上报进度

#### 3.1 页面结构

```
┌────────────────────────────────────┐
│           视频播放器               │
│   ┌──────────────────────────┐    │
│   │     视频画面             │    │
│   │                          │    │
│   │   试看剩余 2:38           │    │  ← 未购买时显示
│   │   [购买完整课程]          │    │  ← 试看结束弹窗
│   │   或  🔒 视频已锁定       │    │  ← 无试看时显示
│   └──────────────────────────┘    │
├────────────────────────────────────┤
│  章节目录                           │
│  ✔️ 第一章：网络基础  (已完成)     │
│  ● 第二章：路由交换  (播放中)   12:05│  ← 显示已播放位置
│    第三章：安全加固             15:30│
│    第四章：实战演练             22:10│
└────────────────────────────────────┘
```

#### 3.2 试看规则

| 条件 | 播放器行为 |
|------|-----------|
| 已购买 | `free_preview_seconds = null` → 无限制播放 |
| 未购买 + `free_preview_seconds = N` | 限制在 0 ~ N-1 秒；到达 N 秒 → 暂停 + 弹窗「购买完整课程」 |
| 未购买 + `free_preview_seconds = null` | 播放器显示「🔒 视频已锁定」蒙层 |

**试看累积追踪**（`localStorage`）：

- Key：`preview:{course_id}`
- Value：`{ total_watched_seconds: number, last_update: timestamp }`
- 每次 play 事件开始计时，pause / 切章节 / 退出时停止，累加 total
- 到达 `free_preview_seconds` 后锁定

#### 3.3 学习进度

**上报时机**：

| 时机 | 触发 |
|------|------|
| 暂停播放 | `POST /api/courses/{id}/progress` |
| 切换章节 | 先报上一节进度，再切到新章节 |
| 页面退出（`onUnload`） | 上报当前进度 |
| 定时心跳（可选） | 每 15 秒上报一次 |

**断点续播**：

进入播放页 → `GET /api/courses/{id}/chapters` → 取 `progress.last_chapter_id` 和 `last_position_seconds` → 自动跳转到对应章节 + 时间点。

**章节标记**：

- ✅ `progress.completed_chapter_ids` 中包含的章节 → 显示「已完成」
- ● 当前播放章节 → 显示播放进度条

#### 3.4 章节被删除的降级

`GET .../chapters` 只返回 `is_active=True` 的章节。如果上次学习的章节已被删除（不在列表中），前端自动 fallback 到第一个可用章节。

## 四、联调验收

**前置条件**：三端全部完成。

### 验收场景

| # | 场景 | 验收要点 |
|---|------|----------|
| 4.1 | 选课 → 播放 → 试看限制 | 未购买用户播放视频，达到试看时长后暂停 + 弹窗 |
| 4.2 | 章节切换 | 切换后播放器正确加载新视频，进度正确上报 |
| 4.3 | 进度恢复 | 退出播放页 → 重新进入 → 自动定位到上次播放位置 |
| 4.4 | 未登录访问 | 章节接口正确返回 `progress=null`、正确返回试看时长 |
| 4.5 | 已购买用户 | `free_preview_seconds=null`，播放器无限制 |
| 4.6 | 章节被删除 | 删除章节后，用户端不显示该章节；断点自动切换 |
| 4.7 | 空章节课程 | 课程无章节时，接口返回空数组，前端不崩溃 |
| 4.8 | 管理后台全流程 | 新建课程 → 设置试看 → 添加章节 → 排序 → 上/下架 → 小程序验证 |
| 4.9 | 学习进度并发 | 快速切换章节时，后端 `last_position_seconds` 不回退 |
