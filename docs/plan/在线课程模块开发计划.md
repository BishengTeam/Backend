# 在线课程模块开发计划（v2 — 修正版）

> 目标：从 0 到 1 完成在线课程模块，覆盖课程章节管理、视频播放、学习进度等完整业务流程。
>
> 本版基于多轮评审修正，关键决策已确认：
> - 试看 = 课程级别，前 N 秒连续试看，前端本地追踪
> - 购买 = 整个课程，不按章节
> - 删除 = 软删除（is_active=False）
> - 订单/支付部分暂不涉及（由另一位开发者负责）

## 1. 数据模型

### 1.1 Course 模型新增字段

```python
# domain/certification/src/model/course.py — 新增字段
free_preview_seconds: Mapped[int | None] = mapped_column(Integer, nullable=True)
# null = 无试看；非 null = 该课程前 N 秒可试看
```

保留现有 `video_url`，语义为「课程介绍/宣传视频」，与章节学习视频区分。

### 1.2 新建 CourseChapter 表

```python
# domain/certification/src/model/course_chapter.py
class CourseChapter(Base, TimestampMixin):
    __tablename__ = "course_chapter"
    __table_args__ = (
        UniqueConstraint("course_id", "sort_order", name="uq_course_chapter_sort"),
    )

    course_id: Mapped[int] = mapped_column(
        Integer, ForeignKey("course.id"), nullable=False, index=True
    )
    title: Mapped[str] = mapped_column(String(256), nullable=False)
    video_url: Mapped[str | None] = mapped_column(String(512))
    duration: Mapped[int | None] = mapped_column(Integer)       # 秒，前端自动获取
    sort_order: Mapped[int] = mapped_column(Integer, default=0)
    is_active: Mapped[bool] = mapped_column(default=True)       # 软删除开关

    course: Mapped["Course"] = relationship(back_populates="chapters")
```

### 1.3 Course 反向关联

```python
# domain/certification/src/model/course.py — Course 模型新增
chapters: Mapped[list[CourseChapter]] = relationship(
    back_populates="course", order_by="CourseChapter.sort_order"
)
```

### 1.4 新建 UserChapterProgress 表

```python
# domain/certification/src/model/user_chapter_progress.py
class UserChapterProgress(Base, TimestampMixin):
    __tablename__ = "user_chapter_progress"
    __table_args__ = (
        UniqueConstraint("user_id", "course_id", "chapter_id", name="uq_user_chapter_progress"),
    )

    user_id: Mapped[int] = mapped_column(
        Integer, ForeignKey("user.id"), nullable=False, index=True
    )
    course_id: Mapped[int] = mapped_column(
        Integer, ForeignKey("course.id"), nullable=False, index=True
    )
    chapter_id: Mapped[int] = mapped_column(
        Integer, ForeignKey("course_chapter.id"), nullable=False
    )
    last_position_seconds: Mapped[int] = mapped_column(Integer, default=0)
    is_completed: Mapped[bool] = mapped_column(default=False)
```

### 1.5 domain index 导出

## 2. 后端接口

### 2.1 用户端（`/api` 前缀）

#### 课程章节列表

```
GET /api/courses/{course_id}/chapters
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| course_id | int(path) | ✅ | 课程 ID |

**认证**：可选登录（`get_current_user_optional`）。

**响应**：

```json
{
  "code": 0,
  "data": {
    "free_preview_seconds": 300,
    "chapters": [
      {
        "id": 1,
        "title": "第一章：网络基础",
        "video_url": "https://cdn.example.com/xxx.mp4",
        "duration": 1800,
        "sort_order": 1
      }
    ],
    "progress": {
      "last_chapter_id": 2,
      "last_position_seconds": 125,
      "completed_chapter_ids": [1]
    }
  }
}
```

**行为**：
- 始终返回全部 `is_active=True` 的章节，按 `sort_order` 升序
- 未登录或未购买：`free_preview_seconds` 返回 `Course.free_preview_seconds`（null 表示无试看，前端锁定所有章节）
- 已购买（`has_access=True`）：`free_preview_seconds` 返回 `null`，前端不限制播放
- `progress` 始终返回（已登录时），未登录时返回 `null`

#### 课程详情增加章节字段

`GET /api/courses/{course_id}` 的 `CourseDetailResponse` 新增：

```python
chapters: list[ChapterResponse] = Field(default_factory=list)
free_preview_seconds: int | None = Field(None)
```

行为与章节列表接口一致。`Course.video_url` 保留不变（介绍视频）。

#### 学习进度

```
GET  /api/courses/{course_id}/progress    查询进度
POST /api/courses/{course_id}/progress    上报进度
```

**POST 请求体**：

```json
{
  "chapter_id": 2,
  "last_position_seconds": 125,
  "is_completed": false
}
```

- 前端播放器在暂停、切换章节、退出时上报
- 后端 upsert `UserChapterProgress`
- `is_completed=true` 当 `last_position_seconds >= duration - 5`（5 秒容差，后端自动判）

### 2.2 管理后台（`/admin` 前缀）

全部需要 `course:write` 权限。路由按以下顺序注册（**sort 必须在 {chapter_id} 之前**）：

#### 章节列表

```
GET /admin/courses/{course_id}/chapters
```

| 参数 | 类型 | 说明 |
|------|------|------|
| is_active | bool(query) | 筛选上架/下架，可选 |
| page | int | 页码，默认 1 |
| page_size | int | 每页，默认 20，最大 100 |

返回分页数据，含已下架的章节。

#### 新增章节

```
POST /admin/courses/{course_id}/chapters
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | str | ✅ | 最长 256 |
| video_url | str | 否 | 视频链接 |
| duration | int | 否 | 时长（秒），前端自动获取后传入 |
| sort_order | int | 否 | 排序，默认追加到末尾 |

#### 编辑章节

```
PUT /admin/courses/{course_id}/chapters/{chapter_id}
```

所有字段可选，只更新传入的字段。

#### 删除章节

```
DELETE /admin/courses/{course_id}/chapters/{chapter_id}
```

软删除（`is_active=False`），不删数据。用户端不再返回该章节，前端提示"此章节已关闭"。

#### 批量排序

```
PUT /admin/courses/{course_id}/chapters/sort
```

```json
[
  { "id": 3, "sort_order": 1 },
  { "id": 1, "sort_order": 2 },
  { "id": 2, "sort_order": 3 }
]
```

> ⚠️ 并发提示：如果多位管理员同时编辑排序，后提交者会覆盖前者的变更。建议前端在排序提交前先拉取最新列表。

### 2.3 管理后台课程 schema 新增字段

- `AdminCourseCreate` / `AdminCourseUpdate` / `AdminCourseListItem` 新增 `free_preview_seconds: int | None`

## 3. 试看机制

| 维度 | 方案 |
|------|------|
| 粒度 | 课程级别（`Course.free_preview_seconds`） |
| 方式 | 视频前 N 秒连续试看（如 3 分钟 = 0s ~ 179s） |
| 配置 | 管理后台课程编辑时设置，null = 无试看 |
| 追踪 | 前端本地存储（localStorage），后端不参与 |
| 未购买行为 | 返回全部章节 + `free_preview_seconds`，前端播放器限制在 0~N-1 秒 |
| 已购买行为 | `free_preview_seconds` 返回 null，前端不限制 |

## 6. 关键约束与风险

| 约束 | 说明 |
|------|------|
| 模型位置 | `domain/certification`（与 Course 同域） |
| 接口风格 | 统一 `APIResponse` 包装 |
| 权限 | 沿用 `course:write` / `course:list` |
| 路由顺序 | 管理端 `PUT .../chapters/sort` 必须在 `PUT .../chapters/{chapter_id}` 之前注册 |
| 软删除 | 章节删除只设 `is_active=False`，不删数据 |
| Course.video_url | 保留不变，语义为「课程介绍/宣传视频」 |
| 试看 | 课程级别 `free_preview_seconds`，管理员可配，前端本地追踪 |
| 防盗链 | 阶段 3 再实现签名 URL，阶段 1 返回原始 URL |
| 订单/支付 | 搁置，不在此次范围 |

| 风险 | 影响 | 应对 |
|------|------|------|
| 管理端排序并发覆盖 | 低（单人操作场景为主） | 接口文档提示 |
| 前端切换订单流程后 enroll 废弃 | 中 | enroll 此次不动，后续由另一位开发者决策 |
| `Course.video_url` 与章节视频语义混淆 | 低 | 文档中明确区分 |
