# 在线课程业务流程

## 核心规则

- 课程价格只读取后端 `Course.price`。
- 免费课程直接创建 `enrolled` 报名，不创建订单。
- 付费课程创建 `pending` 订单和 `pending_payment` 报名，支付前不得访问私有内容。
- 支付、退款、关单通过统一履约回调更新报名，并与订单状态在同一事务提交。
- 下架仅禁止新购买，已有学习权限不受影响。
- 课程资源存放在私有目录，通过资源接口逐次鉴权。

## 购买流程

```mermaid
flowchart TD
    A[用户查看课程列表] --> B[查看课程详情和试看内容]
    B --> C[点击购买或报名]
    C --> D{课程是否上架}
    D -->|否| E[拒绝购买]
    D -->|是| F{是否已有有效报名}
    F -->|已开通| G[返回现有学习权限]
    F -->|待支付| H[返回原待支付订单]
    F -->|没有| I{课程价格是否为0}
    I -->|是| J[创建 enrolled 报名并开通权限]
    I -->|否| K[创建 pending 订单和 pending_payment 报名]
    K --> L[发起微信支付]
    L --> M{支付结果}
    M -->|成功| N[订单 completed + 报名 enrolled]
    M -->|未支付| O[保持待支付]
    O --> P[超时关闭订单 + 报名 cancelled]
    J --> Q[访问私有课程内容]
    N --> Q
    Q --> R{是否退款}
    R -->|否| Q
    R -->|是| S[订单 refunded + 报名 refunded 并撤权]
```

## 报名状态

```mermaid
stateDiagram-v2
    [*] --> enrolled: 免费课程
    [*] --> pending_payment: 付费课程
    pending_payment --> enrolled: 支付成功
    pending_payment --> cancelled: 订单超时关闭
    enrolled --> completed: 完成学习
    enrolled --> refunded: 退款成功
    completed --> refunded: 退款成功
    refunded --> [*]
    cancelled --> [*]
```
