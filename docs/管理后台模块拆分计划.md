## 审计标准（每个模块交付前自查）

### 后端接口审计

| # | 检查项 | 标准 |
|---|--------|------|
| A1 | 路由注册 | 新路由已在 `Backend/app/api/admin/__init__.py` 注册 |
| A2 | 权限控制 | 每个路由有 `Depends(require_permission(...))` 鉴权 |
| A3 | Schema 完整 | Create / Update / ListItem schema 字段覆盖模型所有管理字段 |
| A4 | 分页支持 | 列表接口返回 `PaginatedData` 格式 |
| A5 | 软删除 | DELETE 操作设 `is_active = False` 而非物理删除 |
| A6 | 错误码一致 | 404 用 `NotFoundException`，参数校验用 Pydantic `Field` |
| A7 | 响应格式 | 所有接口返回 `APIResponse[T]`，成功用 `success(data=...)` |

### 前端页面审计

| # | 检查项 | 标准 |
|---|--------|------|
| F1 | 路由注册 | 页面已在 `Admin/src/routes.tsx` 注册，含 meta.title/icon/permission |
| F2 | 列表加载 | 首次加载正常渲染列表，空数据 show empty |
| F3 | 加载状态 | 请求中显示 loading，失败显示错误提示 |
| F4 | 分页正确 | 切换页码/每页条数正确发送 page/page_size |
| F5 | 搜索筛选 | 筛选项变化后重置到第 1 页 |
| F6 | 新增/编辑 | 表单校验正确，提交后列表刷新，关闭抽屉/弹窗 |
| F7 | 删除确认 | 删除操作弹出确认框，确认后执行 |
| F8 | 状态切换 | 上架/下架开关即时生效，操作后刷新列表 |
| F9 | 类型安全 | Service 方法有泛型类型标注，不裸用 `any`（框架边界除外）|
| F10 | 图标无冲突 | icon 名称在 ant-design/icons 中存在且无重复 |

### 字段对齐审计

| # | 检查项 | 标准 |
|---|--------|------|
| D1 | 创建字段 | 前端表单字段 ⊆ 后端 Create schema 字段 |
| D2 | 列表字段 | 后端 ListItem schema 字段 ⊇ 前端列表列使用的字段 |
| D3 | 编辑回显 | 列表返回字段 ⊇ 编辑表单 setFieldsValue 使用的字段 |
| D4 | 字段命名 | 前后端字段名完全一致（snake_case） |
| D5 | 可选字段 | null-safe：后端 Optional 字段前端用 `??` 或 `||` 兜底 |
