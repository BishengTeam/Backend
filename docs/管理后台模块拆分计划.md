```
Admin 后台
```

## 模块分项

### 1. 课程管理

| 项 | 状态 |
|----|------|
| 后端 CRUD | ✅ `GET/POST/PUT/DELETE /admin/courses` |
| 前端页面 | ✅ `Admin/src/pages/content/courses.tsx` |
| 表单字段 | ⚠️ 缺 description/cover_url/video_url |

**清单**:
- [ ] CourseModal 表单加封面图、描述、视频URL 字段
- [ ] 课程列表列加封面缩略图
- [ ] 从 routes.tsx 独立为一级菜单 `content/courses` → `courses`

**数据模型**:
```
Course: title, category, description, cover_url, video_url, price,
        batches(JSON), teacher_name, teacher_contact, is_active
```

---

### 2. 活动管理（复用 Zone, zone_type='activity'）

| 项 | 状态 |
|----|------|
| 后端 CRUD | ✅ 复用 `/admin/zones`，过滤 zone_type=activity |
| 前端页面 | ⚠️ 需新建 `Admin/src/pages/activity/index.tsx` |

**清单**:
- [ ] 新建活动管理页面（复用 ContentEditDrawer 组件）
- [ ] 后端加 `GET /admin/zones?zone_type=activity` 筛选支持
- [ ] 路由: `activity` → icon: `CalendarOutlined`

**数据模型**:
```
Zone(zone_type='activity'): title, cover_url, description,
     link_url(外链), is_active, is_banner=false
```

> 设计理由: 活动当前仅外链，字段与 Zone 完全重合，无需新建表。

| 项 | 状态 |
