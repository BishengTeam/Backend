# NISP 审核页批次查询

`GET /admin/nisp/review-batch-options` 要求 `nisp:review`，返回标准分页数据：

```json
{
  "items": [{ "id": 18, "name": "秋季考试", "level": "2", "status": "archived" }],
  "total": 1,
  "page": 1,
  "page_size": 20
}
```

`id` 是 `NispExamBatch.id`，名称和状态来自关联的 `Plan`。查询包含全部批次状态，按批次 ID 倒序排列；同名批次分别返回，前端使用级别和 ID 区分。接口仅投影这四个字段。

- `keyword` 可选，最长 64 字符：去除两端空格后按名称模糊匹配；纯数字也精确匹配批次 ID，`#18` 可直接按编号定位。
- `page` 默认 1，最小 1；`page_size` 默认 20，范围 1–100。
- 批次管理接口继续要求 `nisp:batch_manage`。

报名响应增加可选 `batch_name: string | null`，默认 `null`，有对应计划时返回 `Plan.name`。审核列表继续使用已有 `batch_id` 参数，并与级别、报名状态、关键词、付款状态、有效导出筛选共同生效。无需数据库迁移。
