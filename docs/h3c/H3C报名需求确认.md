# H3C 报名需求确认

> 确认日期：2026-08-17  
> 来源：与南风/黄老师的业务沟通，以及对三份新华三 Excel 模板的逐项读取。  
> 状态：需求记录，暂不代表已完成代码实现。

## 一、报名类型与模板

华三报名按报名类型使用独立模板，不混用：

| 报名类型 | 对应模板 | 业务说明 |
| --- | --- | --- |
| 考券报名 | `新华三-H3C考券报名模板.xlsx` | 考生参加新华三大赛获奖，由厂商赠送考券，考生拥有考券号 |
| 全额报名 | `新华三-全额报名模板.xlsx` | 没有优惠券的社会考生，按全额报名 |
| 学生报名 | `新华三-学生报名模板.xlsx` | 学生身份享受补贴，需要提交学生身份验证材料 |

## 二、特殊字段与附件

### 2.1 考券报名

- 考券号：必填，由考生提交。
- 优惠券证明图片：必填。
- 图片格式：JPG。
- 业务上暂未规定图片大小上限。

### 2.2 学生报名

- 学生证明图片：必填。
- 学信网在线验证码：必填。
- 学生证明图片和在线验证码必须同时提交，不能互相替代。
- 图片格式：JPG。
- 业务上暂未规定图片大小上限。

### 2.3 全额报名

- 不需要提交考券号。
- 不需要提交优惠券证明图片。
- 不需要提交在线验证码。

### 2.4 业务规则优先级

Excel 表头使用 `*` 标记通常必填字段，但最新业务确认覆盖表格中未加 `*` 的特殊字段规则：

- 考券报名的考券号和证明图片必须填写。
- 学生报名的证明图片和在线验证码必须填写。
- 因此不能只根据 Excel 中是否带 `*` 判断后端字段是否必填。

## 三、模板读取结果

### 3.1 考券报名模板

表头带 `*` 的字段：

- 考券号、姓名、性别、身份证号
- 所属单位或学校、通信地址、电话、E-mail
- 国别、语言 ID、学历
- 身份标签、First Name、Last Name
- 考试时间、考试代码

表头未带 `*` 的字段：

- 学生/内部员工优惠券证明图片
- 在线验证码
- 出生年月、考生号
- 培训机构、培训地址、培训开始时间、培训结束时间

表内说明指出：优惠券证明图片用于学生/内部员工优惠券；学生优惠券提供学信网在线验证码；新增考生应复制示例行。模板中包含一张嵌入式 PNG 示例图片。

### 3.2 全额报名模板

表头带 `*` 的字段：

- 考试代码、姓名、性别、身份证号
- 所属单位或学校、通信地址、电话、E-mail
- 国别、语言 ID、学历
- 身份标签、First Name、Last Name
- 考试时间

表头未带 `*` 的字段：

- 出生年月、考生号
- 培训机构、培训讲师、培训开始时间、培训结束时间

该模板没有优惠券证明图片列、在线验证码列，也没有嵌入图片。

### 3.3 学生报名模板

表头带 `*` 的字段：

- 考试代码、姓名、性别、身份证号
- 所属单位或学校、通信地址、电话、E-mail
- 国别、语言 ID、学历
- 学生证明图片
- First Name、Last Name、考试时间

表头未带 `*` 的字段：

- 在线验证码
- 出生年月、考生号
- 培训机构、培训讲师、培训开始时间、培训结束时间

表内说明：如果没有学信网在线验证码，可上传有学院盖章的学籍证明图片；如果提供在线验证码，应上传身份证人像一面清晰图片用于核验学籍信息。该说明与最新业务规则“证明图片和在线验证码都必填”不一致，当前以最新业务口头确认为准。模板中包含两张嵌入式 PNG 示例图片。

### 3.4 模板公共结构

- 主工作表名称为“模板”。
- 另有隐藏的 `Sheet1`，包含总部组织选项。
- 下拉选项包括性别、语言、学历、身份标签等。
- 考试时间、出生年月、培训起止时间等字段在表头中写有日期格式说明。
- 模板中的示例图片是 PNG；业务上传图片要求为 JPG。导出时需要明确图片转换/嵌入方式。

## 四、导出要求

### 4.1 文件名

文件名由模板名称去掉“模板”后追加日期，例如：

```text
华三-H3C考券报名-20260817
```

对应文件预计使用 `.xlsx` 或 `.zip` 扩展名。重复导出不允许覆盖旧文件，文件名需自动追加时间，例如：

```text
华三-H3C考券报名-20260817-171800.xlsx
华三-H3C考券报名-20260817-171800.zip
```

### 4.2 下载方式

同一报名类型支持两种下载方式，后台需要提供选项选择：

1. **图片内嵌 Excel**：证明图片直接放入对应报名模板的 Excel。
2. **附件包**：单独打包下载，附件包中只有图片，不包含 Excel。

### 4.3 导出筛选

- 按报名类型选择导出：考券报名、全额报名、学生报名。
- 未审核通过的数据是否导出，需要由管理员单独选择。
- 未审核数据导出是导出筛选项，不代表存在二审流程。

## 五、审核范围

- 华三不需要二审位置，不设计独立二审阶段、二审角色或二审状态。
- 关于“考生信息填错后通知修改”的退回修改窗口，本阶段暂不考虑，后续另行确认和设计。

## 六、暂未确认事项

以下内容仍需要业务或运维确认后才能固化实现：

1. 考券号的长度、字符范围、前缀和重复使用规则。
2. “未审核通过”具体包含哪些状态，以及导出选项默认是否关闭。
3. 按报名类型是单选还是允许一次多选。
4. 附件图片文件名中“图片内容”的固定词，例如“学生证明图片”“优惠券证明图片”。
5. 同名考生是否需要追加序号。
6. 附件 ZIP 的目录结构（当前仅确认 ZIP 只包含图片）。
7. OSS 上传、访问权限、保存期限和导出文件保存规则。
8. 图片无业务大小限制时，系统是否采用流式上传、分片上传等技术方案。

## 七、与现有后端的差异

当前 H3C 请求模型将优惠券号、在线验证码和优惠券证明图片统一设为必填，无法区分考券、学生和全额报名；当前后台导出也只是通用订单 CSV。后续实现需要按报名类型进行条件校验，并新增 H3C 模板化导出能力。
