# 课程模块全链路开发 Todo

> 版本：2026-08-17 第一版
> 状态：`DOING（Backend/Admin 主链路已完成，Platform、访问模式转换治理和 UAT 未完成）`
> 范围：Backend、Admin、Platform 小程序、部署运维与 UAT
> 关联模块：题库 V2、订单支付、私有 OSS、审计与后台权限

## 1. 文档定位

本文是课程管理模块的唯一有效开发清单，覆盖课程内容、课程购买、学习进度、课程与题库权益联动、后台管理、小程序展示、部署和验收。

现有课程相关代码只作为可复用基线，不能直接视为本模块完成。实施过程中如业务规则变化，必须先更新本文，再同步契约、三端类型、测试和验收标准。

## 2. 当前基线

### 2.1 已存在能力

- `course`、`course_chapter`、`course_enrollment`、`course_asset` 领域模型。
- 用户课程列表、课程详情、章节学习、报名/购买、我的课程接口。
- 题库侧已有 `quiz_course_library_binding` 课程-题库绑定表。
- 题库侧已有 `quiz_library_entitlement` 课程订单权益表。
- 付费课程订单结算后可按当时有效绑定幂等发放题库权益。
- 课程退款后可撤销该订单发放的题库权益。
- 课程详情已有赠送题库展示基础。
- Admin 题库模块已有课程选择器，可把 `course_entitlement` 题库绑定到课程。

### 2.2 已识别缺口

- 课程只有 `is_active`，缺少 `draft / published / offline / archived` 生命周期。
- 课程仍带班次字段，但业务已冻结为纯在线网课，不允许继续暴露班次。
- 免费课程没有订单，当前题库权益来源只支持 `course_order`，无法表达免费课程报名后的权益。
- 课程与题库绑定的变更缺少影响预览、异步回补、失败重试和执行记录。
- 解绑题库时需要撤销或保留权益的规则尚未落成服务与页面。
- 课程资料与视频的私有存储、短签、防盗链和访问审计还不完整。
- Admin 课程页面仍在“内容配置”下，未升级为一级课程管理工作台。
- 课程状态、审计、权益影响、回补任务和报名学员视角缺少完整页面。
- 旧课程数据明确为假数据，不做历史兼容迁移；允许删除后按新模型覆盖。

## 3. 冻结业务规则

### 3.1 课程定位

- 课程仅为在线网课视频，不存在线下班次、日期、地点和上课安排。
- 课程学习有效期永久。
- 课程完成后不影响学习权限和题库权益。
- 课程价格允许为 0 元。
- 0 元课程用户报名后立即获得课程权益。
- 付费课程在支付成功后自动获得课程权益。
- 不提供后台手工给用户开通课程的入口。
- 课程试看只允许观看章节内容，不发放课程权益，也不发放题库权益。

### 3.2 课程生命周期

| 状态 | 含义 | 公开列表 | 新购 | 已购学习 | 新增题库绑定 |
|---|---|---:|---:|---:|---:|
| `draft` | 草稿 | 否 | 否 | 否 | 否 |
| `published` | 已发布售卖 | 是 | 是 | 是 | 是 |
| `offline` | 已下线 | 否 | 否 | 是 | 否 |
| `archived` | 已归档 | 否 | 否 | 是 | 否 |

规则：

- `published -> offline`：停止新售；已有待支付订单立即无法支付并被关闭或阻断回调；已购用户继续学习。
- `offline -> published`：允许恢复售卖，需审计。
- `published/offline -> archived`：不再新售，已购用户保留“我的课程”入口。
- 已有关联订单、报名、权益或资产的课程不允许物理删除，只能归档。
- 没有任何业务关联的 `draft` 课程允许物理删除，但必须审计。

### 3.3 课程编辑和调价

- 已发布课程允许编辑。
- 删除章节、替换视频、修改试看时长属于高风险变更，必须二次确认并审计。
- 调价不影响已购用户；新价格只影响新订单。
- 0 元课程和付费课程可以在草稿期自由设置；发布后调价需二次确认。

### 3.4 类目

- 第一期不建设递归类目树。
- 后台维护类目字典。
- 每门课程必须选择一个类目。
- 类目仅用于筛选和展示，不承载权限。

### 3.5 物理删除规则

- 假数据清理允许删除课程域旧数据后重建。
- 以下真实业务对象一旦出现，课程不允许物理删除：
  - 课程订单
  - 课程报名
  - 课程资产访问记录
  - 题库绑定
  - 题库权益
  - 学习进度
- 无业务关联的草稿课程可删除，删除必须写审计。

## 4. 课程与题库联动规则

### 4.1 绑定条件

- 只有 `published` 课程允许新增绑定。
- 只有 `published` 且 `access_mode = course_entitlement` 的题库允许新增绑定。
- `draft`、`suspended`、`archived` 题库不允许新增课程绑定。
- 一个课程可绑定多个题库。
- 一个题库可被多个课程绑定。

### 4.2 绑定新增

新增绑定必须提供执行前影响预览：

- 课程已购用户数。
- 将回补权益的用户数。
- 题库当前状态和内容规模。
- 是否存在进行中的题库会话。

确认后异步回补已购用户：

- 每批建议 500 人。
- 不设总人数上限。
- 支持进度、失败原因、失败重试和执行审计。
- 回补必须幂等，同一课程权益来源和题库不能重复发放。

### 4.3 绑定解绑

解绑前必须提供影响预览：

- 受影响用户数。
- 活跃权益数。
- 进行中的练习/考试会话数。
- 是否存在其他课程来源可维持访问。

确认后：

- 撤销该课程来源发放且无其他有效来源的权益。
- 用户仍持有其他有效来源时可继续访问同一题库。
- 相关进行中会话按题库现有会话失效规则同步关闭或暂停。
- 操作必须审计并可追溯到操作者、绑定、批次和影响统计。

### 4.4 权益来源

| 来源 | 适用课程 | 触发时机 | 生命周期 |
|---|---|---|---|
| `course_order` | 付费课程 | 支付成功 | 全额退款立即撤销 |
| `course_enrollment` | 0 元课程 | 报名成功 | 报名取消或退款时撤销 |

约束：

- 不伪造 0 元订单。
- 不提供 `manual_grant` 手工权益来源。
- 权益默认永久有效。
- 同一题库存在多个有效来源时，任一有效来源即可访问。
- 撤销其中一个来源时必须检查其他有效来源，不能误撤。

### 4.5 退款和订单关闭

- 全额退款成功后，立即撤销该订单发放的题库权益。
- 部分退款规则第一期不实现；如未来出现，必须单独冻结。
- 课程下线后：
  - 不允许创建新订单。
  - 已有待支付订单立即无法支付。
  - 待支付订单应主动关闭；若与支付回调并发，必须在回调事务中锁定课程状态并拒绝开通。
- 课程归档不撤销已购用户权益。

### 4.6 题库状态和访问模式

- 题库暂停时不撤销课程权益；访问返回“题库暂停”。
- 题库恢复后自动继续可用。
- 超级管理员允许修改题库访问模式，但必须展示影响并二次确认。
- 免费题库与课程权益题库互转时，不能让已由课程发放的权益静默失效。
- 权益记录保存发放时快照用于审计；用户实际访问和展示使用题库当前数据。

### 4.7 发放失败

- 课程报名或支付成功不因题库权益发放失败回滚。
- 发放失败进入待重试任务。
- 后台可见失败原因、失败人数、批次和重试按钮。
- 重试仍必须幂等。

## 5. 小程序规则

- 公开课程列表只展示 `published` 课程。
- 课程详情展示：
  - 课程基础信息
  - 类目
  - 价格
  - 章节列表
  - 试看标识
  - 赠送题库基础信息
  - 赠送题库的章节/模块目录列表
- 无课程权益时不展示题目内容或练习入口，仅可展示目录级题库结构。
- 获得课程权益后展示对应题库练习入口。
- 已购课程永久保留在“我的课程”。
- 归档课程对已购用户仍可访问。
- 0 元课程报名成功后立即进入已购课程。
- 付费课程支付成功后立即进入已购课程。

## 6. 课程资料与视频

- 课程资料必须走私有 OSS。
- 资料下载使用短签 URL，有效期不超过 300 秒。
- 资料访问必须校验课程权益和资产归属。
- 资料访问必须审计。
- 视频必须明确来源：
  - 平台私有对象存储短签播放
  - 受允许的外部视频服务
- 外部视频服务必须配置域名白名单。
- 视频访问必须具备有效期或防盗链策略。
- 无权益用户只能访问明确标记为试看的章节或时长。

- 复用同一影响预览规则。
- 对新增绑定触发同一回补流程。
- 不绕过课程状态和题库状态约束。

## 9. 数据与迁移设计

### 9.1 数据清理

旧课程数据为假数据，不做历史兼容迁移：

- 允许删除旧课程、章节、报名、资料、课程-题库绑定和课程权益假数据。
- 删除后按新模型重建。
- 不允许级联删除真实题库、题目、订单流水或支付记录。
- 生产首次执行前仍必须做数据库备份，便于回滚和事故排查。

### 9.2 目标模型调整

课程：

- 删除或停用班次字段。
- 增加生命周期状态。
- 增加类目外键或受控类目值。
- 保留价格、讲师、封面、简介、试看配置。

章节：

- 保留标题、排序、时长。
- 明确视频来源类型。
- 支持私有对象键或外部视频 URL。
- 增加试看标记。

资料：

- 使用私有对象键。
- 保留类型、排序、试看标记。

课程报名：

- 删除班次选择。
- 保留订单关联。
- 0 元课程无订单，直接进入 `enrolled`。

题库权益：

- `source_type` 支持 `course_order` 和 `course_enrollment`。
- 付费来源必须关联订单。
- 免费来源必须关联报名记录。
- 权益唯一约束按来源类型和来源记录幂等。
- 保留课程 ID 和题库 ID。
- 保留发放时题库快照。

权益任务：

- 记录绑定变更、批次、总数、成功数、失败数。
- 支持失败重试。
- 保留操作者和审计摘要。

## 12. 验收场景

1. 草稿课程不出现在小程序，不能购买，不能绑定题库。
2. 发布课程可购买，可管理章节和资料。
3. 0 元课程报名后立即出现在我的课程并获得题库权益。
4. 付费课程支付成功后立即出现在我的课程并获得题库权益。
5. 未购买用户只能试看，不能获得题库权益。
6. 课程详情展示赠送题库基础信息和目录结构。
7. 无权益用户不能进入题库练习或查看题目内容。
8. 发布后新增绑定，已购用户异步回补成功。
9. 解绑题库时，只有无其他有效来源的用户失去访问。
10. 全额退款后该订单发放的题库权益立即撤销。
11. 课程下线后不能新购，待支付订单无法支付，已购用户继续学习。
12. 课程归档后不在公开列表，已购用户仍可学习。
13. 题库暂停时不撤销权益，访问提示暂停，恢复后继续可用。
14. 课程资料下载必须短签、校验权益并审计。
15. 所有高风险管理操作都有确认和审计。
