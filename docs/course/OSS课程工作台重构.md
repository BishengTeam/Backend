# OSS 课程工作台重构设计

## 2026-08-21 冻结决策

- 课程管理拆分为课程列表、类目管理、课程工作台、报名学员和课程审计。
- 新增固定管理员角色 `course_admin`。
- `course_admin` 可管理类目、课程基础信息、封面、章节视频、上下线和日常审计。
- 删除课程、调价、题库绑定/解绑、归档/恢复和权益任务重试仅 `super_admin` 可执行。
- 课程封面和章节视频均存储在现有 Aliyun OSS 私有 Bucket。
- OSS 路径按安装实例隔离：`course/<installation_id>/covers/` 与 `course/<installation_id>/chapters/`。
- 管理后台通过后端签名的 OSS 授权直传；文件不经过 Backend。
- 章节视频使用 multipart 断点续传，未完成分片保留 7 天，已完成未绑定对象保留 24 小时。
- 封面仅支持 JPG/PNG/WebP，最大 10 MB，强制 16:9。
- 章节视频仅支持 MP4/MOV/MKV，最大 5 GB；不做服务端转码，非 MP4 需运营自行确认小程序兼容性。
- 课程价格为后台元单位、最多两位小数；数据库与支付仍保存整数分。
- 试看规则改为课程级 `preview_chapter_count`，仅付费课程生效；未购买用户仅可播放前 N 集。
- 免费课程全部章节可学，报名/购买后保留学习入口。
- 课程发布前必须有封面、价格、启用类目和至少一个带视频与时长的章节；试看集数不能超过章节数。
- 第一版不保留 PDF/课件等课程资料，学习资源仅章节视频。
- OSS 播放地址有效期 5 分钟，由小程序按章节获取并在过期前自动续期。
- OSS CORS 仅允许 Admin HTTPS Origin 和直传所需方法/Headers。

## 迁移

`crs002` 有意清空并重建当前测试课程域，不做旧课程、外部 URL、本地对象键或试看时长兼容。

## 验收

1. 创建课程管理员并确认仅能访问课程管理。
2. 创建一级类目。
3. 上传 16:9 封面并创建课程草稿。
4. 批量上传章节视频，确认待确认列表中的默认标题、排序和时长可编辑。
5. 确认批量创建章节，检查试看标记和发布校验。
6. 超级管理员绑定赠送题库并确认影响预览/回补任务。
7. 小程序验证免费课程全量播放、付费课程前 N 集试看、购买解锁和进度续播。
8. 断网或刷新后台后重新进入课程工作台，选择同一文件继续未完成分片。
