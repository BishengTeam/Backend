## 1. 交付目标

首版必须在生产等价环境完整跑通以下闭环：

1. 管理员维护最多三级分类，创建、编辑、发布、停用和恢复单选、多选、判断题。
2. 管理员通过 CSV/JSON 后台任务原子导入最多 5,000 道草稿题，并查看进度、完整错误、源文件和错误报告。
3. 小程序匿名用户可浏览有效分类树；微信登录后可浏览题目、创建普通练习或错题专项。
4. 练习使用服务端会话和冻结快照；用户逐题显式提交后立即看到判定、标准答案和解析，并可重答。
5. 系统自动维护错题、收藏、自动打卡、完整练习历史和实时个人统计。
6. 用户创建一场 60 分钟模拟考试，自由跳题并自动保存答案；主动交卷或服务端超时后统一结算。
7. 换机、重装、Token 刷新和多设备登录后，用户能恢复唯一活动练习和唯一进行中考试。
8. 管理员查看不含用户身份的题库总览、单题聚合统计以及永久、脱敏、只读的审计日志。
9. 导入、考试超时、统计聚合和 OSS 清理由独立 `quiz-worker` 处理，Web 进程不运行后台循环。
10. 生产环境使用 PostgreSQL、Redis 和私有阿里云 OSS；依赖缺失时启动或 `/ready` 明确失败。
11. Backend、Admin、Platform 使用同一版契约联合发布，不保留旧接口、字段别名、双写或客户端回退。
12. Android、iOS 真机、真实 OSS、并发竞态、10 万题/10 万用户/500 并发容量和恢复演练全部通过。

完成定义不是“接口或页面存在”，而是数据约束、状态机、权限、并发、幂等、答案隔离、三端交互、独立 Worker、外部依赖、性能和恢复均有可复查证据。

## 2. 冻结范围

### 2.1 首版包含

| 维度 | 冻结内容 |
|---|---|
| 客户端 | Admin 管理后台和微信小程序；不新增 H5、PC 用户端或其他客户端 |
| 语言和内容 | 简体中文、纯文本题干/选项/解析，复用现有设计系统和通用组件 |
| 分类和题目 | 最多三级分类；单选、多选、判断；当前内容可编辑，历史会话使用快照 |
| 导入 | CSV/JSON，单文件最大 10 MiB、单任务最多 5,000 题、全量校验、原子入库 |
| 练习 | 普通练习、错题专项、自由跳题、显式逐题提交、即时判分、允许重答 |
| 用户资产 | 系统错题、收藏、自动打卡、完整练习历史、个人练习/考试统计 |
| 模拟考试 | 60 分钟、服务端截止时间、自动保存、主动交卷、超时结算、放弃和历史 |
| 题量选择 | 普通练习和考试 UI 固定 `10/20/50/100`；练习不足时取全部，考试不足时拒绝并返回最大可选数 |
| 管理页面 | 分类、题目、导入任务、聚合统计、审计日志五个逻辑页面；任务监控属于运维辅助页 |
| 权限 | 复用 `quiz:list`、`quiz:write`、`quiz:import`；超级管理员自动拥有全部权限，但题库操作不额外要求超级管理员 |
| 存储 | 生产使用私有阿里云 OSS；随机对象键、匿名访问拒绝、签名最长 300 秒、下载审计、7 天清理 |
| 时区 | API 使用带时区时间；自然日和自动打卡统一使用 `Asia/Shanghai` |
| 发布 | 允许清空旧题库数据重建；Backend、Admin、Platform 必须强制联合发布 |

### 2.2 首版明确不做

- AI 出题、OCR、外部题库同步或内容推荐。
- 主观题、人工阅卷、多选部分分、题目权重、自定义总分或及格线。
- 付费题库、积分、排行榜、评论、分享、通知或订阅消息。
- 图片、HTML、Markdown、公式、音频、视频或多语言题目。
- 收藏专项练习、手动错题维护、手动签到或离线判分/结算。
- 题库、统计、审计或用户逐题数据批量导出。
- 旧题库数据迁移、旧 API 兼容、双写或客户端旧契约回退。

## 5. 业务状态含义

### 5.1 分类和题目

| 领域 | 状态 | 含义 | 可执行动作 |
|---|---|---|---|
| 分类 | `active` | 分类自身启用；仍需全部祖先均启用才对用户有效 | 编辑、移动、停用、受限删除 |
| 分类 | `disabled` | 整棵子树不进入公开题池或新会话；历史快照不受影响 | 编辑、移动、启用、受限删除 |
| 题目 | `draft` | 草稿，不进入用户题池，内容允许暂不完整 | 编辑、发布、从未发布时删除 |
| 题目 | `published` | 发布校验通过，分类链有效时进入新题池 | 编辑、停用 |
| 题目 | `disabled` | 不进入新会话；历史、错题和收藏保留并标记 | 编辑、恢复为 `published` |

题目只允许 `draft -> published -> disabled -> published`；不存在 `published -> draft`，已发布或已停用题不得物理删除。

### 5.2 练习和错题

| 领域 | 状态 | 含义 | 可执行动作 |
|---|---|---|---|
| 练习 | `in_progress` | 当前可提交作答；每用户最多一场 | 浏览、逐题提交、重答、放弃 |
| 练习 | `completed` | 所有题至少首次提交一次后自动完成 | 只读结果和历史 |
| 练习 | `abandoned` | 用户主动放弃；已有作答仍计入统计、错题和打卡 | 只读，可新建下一场 |
| 错题 | `active` | 当前在错题本；来源为练习首答错误或已结算考试错误 | 可进入错题专项 |
| 错题 | `cleared` | 后续不同练习会话首次答对后清除 | 后续答错可重新激活 |

练习永久有效，不自动过期；同会话重答正确不能清错，考试答对也不能清错。

### 5.3 模拟考试

| 状态 | 含义 | 是否计入统计 | 答案可见性 |
|---|---|---:|---|
| `in_progress` | 服务端截止时间前进行中 | 否 | 仅题干、选项和本人已保存选择，无标准答案/解析 |
| `completed` | 用户主动交卷并完成结算 | 是 | 展示最终答案、标准答案、解析、判定和成绩 |
| `timed_out` | 服务端 Worker 或请求兜底超时结算 | 是 | 与 `completed` 相同 |
| `abandoned` | 用户主动放弃，不结算 | 否 | 不返回已保存答案、标准答案、解析或成绩 |

### 5.4 导入任务

| 状态 | 含义 | 可执行动作 |
|---|---|---|
| `queued` | 已接收，等待 Worker 认领 | 查看进度 |
| `validating` | 校验全部行，不写题目表 | 查看进度 |
| `validation_failed` | 存在内容错误，整批创建 0 题 | 下载错误报告；修正文件后新建任务 |
| `importing` | 校验通过，正在单事务创建草稿 | 查看进度 |
| `succeeded` | 全部草稿创建成功 | 查看、下载源文件，不能重试 |
| `failed` | 基础设施或数据库异常 | 具备 `quiz:import` 权限时按原任务幂等重试 |

人工重试只适用于 `failed`，不得把内容校验失败直接重试为成功。

## 6. 页面、按钮和接口调用流程

### 6.1 Admin 五个逻辑页面

| 页面 | 目标路由 | 核心功能 | 允许按钮 |
|---|---|---|---|
| 分类管理 | `/admin/quiz/categories` | 树形浏览、状态、层级、题目影响预览 | 新增、添加子分类、编辑、移动、启用、停用、删除 |
| 题目管理 | `/admin/quiz/questions` | 筛选、详情、草稿编辑、状态和单题统计 | 新增、编辑、发布、停用、恢复、删除草稿、批量发布、批量停用 |
| 批量导入任务 | `/admin/quiz/imports` | 模板、上传、进度、错误、源文件/报告和基础设施重试 | 下载 CSV 模板、下载 JSON 模板、上传、刷新、下载源文件、下载错误报告、重试 |
| 题库聚合统计 | `/admin/quiz/stats` | 全局总览、按条件分页的单题练习/考试聚合 | 查看、筛选、刷新；无编辑、删除或导出 |
| 题库审计日志 | `/admin/quiz/audit-logs` | 按管理员、动作、对象、结果、请求 ID 和时间查询详情 | 查看、筛选、刷新；无编辑、删除或导出 |

规则：

- 五个页面可共用题库布局，但必须有稳定路由、面包屑、权限门禁和可直接刷新入口。
- 所有版本化写操作携带最新 `lock_version`；HTTP 409 后刷新当前数据，不自动重试或覆盖。
- 删除、停用和批量操作必须二次确认；移动前必须调用影响预览。
- 批量发布/停用只接受当前页明确勾选的 ID，单次 1～100 条，不支持“全部筛选结果”。
- 不提供批量删除草稿；单题只在 `draft && !ever_published` 时显示“删除草稿”。
- 题目编辑字段只包含分类、题型、题干、A-D 选项、答案和解析。
- `/admin/quiz/tasks` 可保留为 OPS 辅助页，但不替代上述五个业务页面。

### 6.2 微信小程序页面

| 页面/逻辑页 | 核心行为 |
|---|---|
| 题库首页/分类树 | 分类树允许匿名访问；个人统计和进入其他功能前执行微信登录门禁 |
| 题目浏览 | 登录后按分类浏览题干/选项；不得在无会话状态提交答案 |
| 练习创建与答题 | 选择 `10/20/50/100` 或错题专项；恢复活动会话；自由跳题；显式提交；立即展示判定/答案/解析；允许重答 |
| 练习结果/历史 | 自动完成后展示结果；历史支持分类、题型、正误和日期筛选，并展示冻结快照 |
| 错题本 | 系统自动维护；只能查看或创建最近最多 20 道的错题专项，无手动增删 |
| 收藏 | 可收藏/取消收藏和浏览；不提供收藏专项练习 |
| 打卡/个人统计 | 展示 `Asia/Shanghai` 自动打卡、连续天数以及分离的练习/考试统计 |
| 模拟考试 | 创建/恢复、服务端剩余时间、自由跳题、选择变化自动保存、未答确认、交卷/放弃、结果和历史 |

本地只保存 Token、活动会话 ID、考试 ID、答案保存版本和必要临时 UI 状态。退出、注销或换号必须清除题库缓存；服务端数据始终权威。

### 6.3 用户端核心调用顺序

普通练习：

```text
GET categories（可匿名）
  -> 微信登录
  -> GET practice-sessions/current
  -> 无活动会话时 POST practice-sessions
  -> GET practice-sessions/{id}
  -> POST practice-sessions/{id}/attempts（持久化并复用 idempotency_key）
  -> 自动 completed
  -> GET practice-history / GET stats
```

模拟考试：

```text
GET exams/current
  -> 无活动考试时 POST exams
  -> GET exams/{id}
  -> PUT exams/{id}/answers/{exam_question_id}（携带 lock_version）
  -> POST exams/{id}/submit 或 POST exams/{id}/abandon
  -> GET exams/{id} / GET exams / GET stats
```

考试选择变化即保存但不即时判分；交卷时先展示未答数量并二次确认。退出和断网不暂停服务端 60 分钟倒计时。

### 6.4 权限和管理限流

| 操作 | 权限 | 限流键与额度 |
|---|---|---|
| 管理只读、聚合统计、审计、源文件/报告短签 | `quiz:list` | 短签类每管理员 60 次/分钟 |
| 分类/题目普通写和对应影响预览 | `quiz:write` | 普通写每管理员 120 次/分钟 |
| 批量发布/停用 | `quiz:write` | 每管理员 30 次/分钟 |
| 创建或重试导入 | `quiz:import` | 每管理员 10 次/分钟 |

## 15. 必测业务矩阵

| 场景 | 最低验收 |
|---|---|
| 分类 | 1/2/3 级成功；第 4 级、自引用、循环失败；父分类停用后子树不进入新题池；影响预览与执行重校验一致 |
| 题目 | 三题型边界、同分类题干去重、草稿不完整、发布完整校验、发布后编辑、停用/恢复和仅从未发布草稿删除均正确 |
| 批量 | 明确勾选 1/100 成功，101 拒绝；任一缺失、状态错误或版本冲突时整批不变；不支持全部筛选结果 |
| 导入 | CSV/JSON、10 MiB、5,000 题、全量错误、原子回滚、同任务基础设施重试不重复；校验失败不能重试 |
| OSS | 随机键不含题目/管理员信息；匿名和越权失败；签名 300 秒后失效；源文件/报告下载审计和 7 天删除可重试 |

## 16. Definition of Done

任一 QF 任务只有同时满足以下条件才可标记 `DONE`：

1. 代码、迁移、配置或页面满足该行全部验收标准。
2. 正常路径、失败路径、权限边界和至少一个幂等/并发场景有自动化测试。
3. Backend、Admin 和 MP 的契约、类型、字段、状态和文案同步。
4. 涉及 PostgreSQL、Redis 或 OSS 时必须有真实环境证据；Mock 只能标 `🧪`。
5. 涉及答案或用户数据时完成越权、答案隔离、脱敏、缓存和日志检查。
6. 涉及后台任务时具备队列、心跳、超时、失败原因、重试和进程重启恢复证据。
7. 涉及性能时使用冻结容量和 P95 门槛，不以空库或少量数据结果代替。
8. 有可复查证据链接或文件：测试日志、截图、OpenAPI、迁移日志、监控截图、性能报告或 UAT 签字。
