## 2. 已冻结的 V2 规则

### 2.1 内容和权益

```text
题库（QuizLibrary）
└── 模块（QuizModule）
    └── 知识点（QuizKnowledgePoint）
        └── 逻辑题目（QuizQuestion）
            └── 不可变修订（QuizQuestionRevision）
```

- 只有知识点可以挂题；题库和模块只承担内容、展示和范围语义。
- 题库仅支持 `free` 和 `course_entitlement`；本轮不支持题库单独售卖或其他获取渠道。
- 课程可赠送多个题库；订单结算后按 `order_id + library_id` 幂等发放权益。
- 用户必须登录才能使用小程序功能。无权益题库对用户不可见，直达统一返回 `404 quiz_library_not_found`，题库内不做导购。

### 2.2 练习、考试和修订

- 普通练习支持题库、模块和知识点范围，包含范围内全部当前可用已发布题，不再选择题量。
- 发现同范围未完成练习时，必须询问“继续练习”或“重新开始”。
- 会话自最后一次成功作答起 7 天滚动有效；题库或权益临时停用时暂停倒计时。
- 练习和模拟考试都冻结题目修订及题库/模块/知识点路径快照。
- 发布后编辑产生新修订；旧会话不被新修订覆盖。
- 进行中考试不返回标准答案或解析；交卷或超时结算后才写入错题和修订级统计。

### 2.3 导入和管理后台

- 创建导入任务时只选择题库；文件每行携带模块和知识点路径。
- 文件不能创建题库，也不能把题目挂到模块。
- 缺失模块或知识点时进入“等待分类确认”；管理员查看影响树后，结构和全部草稿题在同一事务创建，任一错误全部回滚。
- Admin 的题目工作台左树统一管理模块和知识点，不再保留重复的独立分类管理页。
- 发布题库中停用模块、知识点、题目或执行批量停用时，Admin 必须显示高风险告警。
- 已发布内容允许编辑；停用后可继续编辑并发布新修订，但不会自动恢复可用状态。
- 题库只有进入 `archived` 后才可逻辑删除；模块、知识点和已发布题目必须先停用并满足引用约束。所有逻辑删除均有 7 天撤销期。
