# 题库模块数据字典与状态机

> 版本：2026-08-11 全链路冻结稿
> 产品定位：学习与模拟考试系统
> 适用项目：`Backend`、`Admin` 管理后台、微信小程序 `Platform` 和部署运维
> 任务依据：[题库模块全链路开发 Todo](./题库模块全链路开发Todo.md)
> 本文是题库模块字段、枚举、状态转换、接口边界和验收口径的唯一实现依据。现有代码、旧接口文档或历史迁移与本文冲突时，以本文为准。

## 1. 全局约定

| 项目 | 冻结规则 |
|---|---|
| 时间 | API 使用带时区 ISO 8601；自然日和连续打卡按 `Asia/Shanghai`；数据库使用带时区时间 |
| 产品范围 | 普通练习、错题专项、收藏浏览、练习历史、自动打卡、个人统计和模拟考试 |
| 题型 | `single_choice`、`multiple_choice`、`judge` |
| 内容 | 首版只支持纯文本，不支持图片、HTML、Markdown 富文本或音视频 |
| 题目版本 | 当前题库不保留版本链；管理员可直接覆盖已发布题目，但历史练习和考试必须使用启动时快照 |
| 历史成绩 | 作答时的题目、标准答案、解析、用户答案和判定结果冻结，题库后续修改不得触发历史重算 |
| 答案格式 | 单选/判断使用字符串，例如 `"A"`；多选使用字符串数组，例如 `["A", "C"]` |
| 登录 | 分类树公开；题目列表及全部学习、收藏、错题和考试接口必须登录 |
| 分页 | 列表统一使用 `page`、`page_size`；默认 20，最大 100 |
| 题量 UI | 普通练习和模拟考试固定提供 `10/20/50/100` 四档；API 仍执行服务端范围和可用题量校验 |
| 用户数据 | 用户账号有效期间永久保留；账号注销时交由统一隐私清理或匿名化流程处理 |
| 管理审计 | 永久保留，管理员不能修改或删除 |
| 客户端缓存 | 只保存 Token、活动会话/考试 ID、保存版本和必要临时状态；退出、注销或换号时清除 |
| 生产存储 | 导入源文件和报告只进入私有阿里云 OSS；随机对象键、匿名拒绝、短签最长 300 秒 |
| 后台任务 | 生产由独立 `quiz-worker` 处理导入、考试超时、统计聚合和 OSS 清理；Web 不运行这些循环 |
| 兼容性 | 新版直接替换 `/api/quiz/*` 和 `/admin/quiz/*` 契约，不保留旧接口兼容层 |
| 容量基线 | 10 万道题、10 万用户、500 个并发活跃用户 |

## 2. 枚举

### 2.1 分类状态 `QuizCategoryStatus`

| 值 | 含义 |
|---|---|
| `active` | 分类自身启用；是否对用户有效还需检查全部祖先分类 |
| `disabled` | 分类停用；整棵子树不得进入公开题目列表、新练习或新考试 |

### 2.2 题目状态 `QuizQuestionStatus`

| 值 | 含义 |
|---|---|
| `draft` | 草稿，不进入用户题池；允许内容不完整 |
| `published` | 已发布，满足全部发布校验且所属分类链全部有效时进入题池 |
| `disabled` | 已停用，不进入新题池；历史快照和收藏引用继续保留 |

```text
draft -> published -> disabled -> published
  |
  +-> physical delete          # 仅从未发布的草稿
```

- 已发布题目编辑后仍保持 `published`，保存成功即影响新会话。
- `published` 和 `disabled` 题目不得物理删除。
- 题目没有 `published -> draft` 转换。

### 2.3 练习会话类型 `QuizPracticeMode`

| 值 | 含义 |
|---|---|
| `normal` | 用户选择分类和题数的普通练习 |
| `wrong` | 最近有效错题专项，固定最多 20 题 |

### 2.4 练习会话状态 `QuizPracticeSessionStatus`

```text
in_progress -> completed
            -> abandoned
```

| 值 | 含义 |
|---|---|
| `in_progress` | 可提交作答；同一用户最多一条 |
| `completed` | 本轮每道题至少完成一次提交后自动完成；完成后只读 |
| `abandoned` | 用户主动放弃；已有作答永久保留并继续计入统计和错题本 |

练习会话永不自动过期。用户必须完成或主动放弃现有会话后才能开始新会话。

### 2.5 错题状态 `QuizWrongStatus`

```text
active -> cleared -> active
```

| 值 | 含义 |
|---|---|
| `active` | 当前位于错题本 |
| `cleared` | 已在后续不同练习会话的首次作答中答对 |

错题本完全由系统维护，不提供手动添加或移除接口。

### 2.6 模拟考试状态 `QuizExamStatus`

```text
in_progress -> completed       # 用户主动交卷
            -> timed_out       # 服务端超时结算
            -> abandoned       # 用户主动放弃
```

| 值 | 是否计分 | 是否进入考试统计 | 是否展示答案/解析 |
|---|---:|---:|---:|
| `in_progress` | 否 | 否 | 否 |
| `completed` | 是 | 是 | 是 |
| `timed_out` | 是 | 是 | 是 |
| `abandoned` | 否 | 否 | 否 |

### 2.7 导入任务状态 `QuizImportStatus`

```text
queued -> validating -> importing -> succeeded
                    |             -> failed
                    -> validation_failed
                    -> awaiting_category_confirmation -> queued
                                                     -> cancelled
                                                     -> expired
```

| 值 | 含义 |
|---|---|
| `queued` | 已接收，等待后台任务认领 |
| `validating` | 解析并校验全部行，不写题目表 |
| `validation_failed` | 存在一条或多条行级错误，整批不导入 |
| `importing` | 校验全部通过，正在单事务写入 |
| `awaiting_category_confirmation` | 文件内存在可创建的缺失分类，等待管理员查看影响树并确认 |
| `succeeded` | 全部题目以草稿状态创建成功 |
| `failed` | 基础设施或数据库异常，可按原任务幂等重试 |
| `cancelled` | 管理员取消等待分类确认的任务，不创建分类或题目 |
| `expired` | 等待分类确认超过保留期，任务失效 |

## 3. 分类 `quiz_category`

### 3.1 字段

| 字段 | 类型 | 规则 |
|---|---|---|
| `id` | bigint | 主键 |
| `name` | varchar(128) | 必填，去除首尾空白后非空 |
| `normalized_name` | varchar(128) | 规范化名称；同一父分类下唯一 |
| `parent_id` | bigint nullable | 自关联；空值表示一级分类 |
| `depth` | smallint | 只能为 1、2、3，由服务端计算 |
| `description` | varchar(256) nullable | 纯文本 |
| `status` | enum | `active` / `disabled` |
| `sort_order` | int | 默认 0；同级按 `sort_order ASC, id ASC` 展示 |
| `ever_had_question` | bool | 一旦创建过题目永久为 true，用于限制物理删除 |
| `lock_version` | int | 乐观锁版本，从 1 开始 |
| `created_by` | bigint | 创建管理员 |
| `updated_by` | bigint | 最后修改管理员 |
| `created_at` / `updated_at` | timestamptz | 标准时间字段 |

### 3.2 不变量

- 分类最多三级。
- 禁止自身作为父级、循环引用、移动后超过三级。
- 同一父级下规范化名称唯一。
- 选择父分类时，题目范围递归包含该分类及全部后代分类。
- 分类的有效状态由自身及全部祖先共同决定。任一祖先为 `disabled` 时，后代对用户均无效。
- 停用父分类不批量改写子分类自身状态。
- 仅 `ever_had_question=false` 且没有子分类的空分类可物理删除。
- 公开分类树隐藏没有任何有效已发布题目的整条分支。
- 公开 `question_count` 递归统计有效子树中的 `published` 题目，不统计草稿或停用题目。

## 4. 题目 `quiz_question`

### 4.1 字段

| 字段 | 类型 | 规则 |
|---|---|---|
| `id` | bigint | 主键 |
| `category_id` | bigint | 所属分类；创建和移动时必须存在且不超过三级 |
| `question_type` | enum | `single_choice` / `multiple_choice` / `judge` |
| `status` | enum | `draft` / `published` / `disabled` |
| `question_text` | varchar(1024) | 纯文本题干 |
| `normalized_question_text` | varchar(1024) | 去除首尾空白并合并连续空白后的题干 |
| `question_text_hash` | char(64) | 规范化题干摘要；与 `category_id` 组成唯一约束 |
| `options` | jsonb nullable | 结构化选项对象，键只能为连续的 `A-D`；未完成草稿可空 |
| `correct_answer` | jsonb nullable | 单选/判断为字符串，多选为规范排序后的字符串数组；未完成草稿可空 |
| `explanation` | varchar(1024) nullable | 草稿可空；发布必须非空 |
| `ever_published` | bool | 一旦发布永久为 true |
| `published_at` | timestamptz nullable | 首次发布时间 |
| `disabled_at` | timestamptz nullable | 最近停用时间 |
| `lock_version` | int | 乐观锁版本，从 1 开始 |
| `created_by` / `updated_by` | bigint | 管理员引用 |
| `created_at` / `updated_at` | timestamptz | 标准时间字段 |

### 4.2 题型校验

| 题型 | 选项 | 正确答案 | 判分 |
|---|---|---|---|
| 单选 | 3 至 4 项；键为 `A-C` 或 `A-D` | 单个现有选项键 | 完全匹配 |
| 多选 | 固定 4 项；键为 `A-D` | 2 至 4 个现有选项键；允许四项全选 | 去重、排序后完全匹配；不提供部分分 |
| 判断 | 固定 `A=正确`、`B=错误`，管理员不可修改 | `A` 或 `B` | 完全匹配 |

- 选项值去除首尾空白后必须非空。
- 单选/多选选项键必须连续，不接受自定义键。
- 多选请求中的重复选项先去重，再按字母升序规范化；存在未知选项时拒绝请求。
- 草稿可以暂时不满足发布完整性，但任何 `published` 保存操作都必须执行全部校验。
- 同一分类内规范化题干不得重复；不同分类允许相同题干。
- 已停用题恢复为 `published` 时保留 `disabled_at`，该字段始终表示最近一次停用时间。
- 首版不设置难度、权重、标签、来源年份、图片或富文本字段。

## 5. 当前题目与历史快照

题库当前内容允许覆盖编辑，但任何已经开始的练习或考试都不得直接引用可变题目内容进行展示或判分。

快照必须至少包含：

- 原题目 ID、原分类 ID、分类名称或路径。
- 题型、题干、选项。
- 当时标准答案和解析。
- 原题目 `lock_version` 或 `updated_at`。
- 会话内固定位置 `position`。

规则：

- 练习和考试创建时一次性冻结题目集合及随机顺序。
- 当前会话使用快照，不受题目编辑、移动或停用影响。
- 练习历史和已结算考试历史始终展示快照。
- 历史响应可附带当前题目的 `status`、`updated_at`，但不得用当前内容替换快照。

## 6. 练习会话

### 6.1 `quiz_practice_session`

| 字段 | 类型 | 规则 |
|---|---|---|
| `id` | bigint | 主键 |
| `user_id` | bigint | 用户 |
| `mode` | enum | `normal` / `wrong` |
| `category_id` | bigint nullable | 普通练习必填；错题专项为空 |
| `requested_count` | int | 用户请求题数；错题专项固定请求 20 |
| `actual_count` | int | 实际快照题数 |
| `status` | enum | `in_progress` / `completed` / `abandoned` |
| `started_at` | timestamptz | 开始时间 |
| `completed_at` | timestamptz nullable | 自动完成时间 |
| `abandoned_at` | timestamptz nullable | 主动放弃时间 |
| `lock_version` | int | 并发状态变更版本 |

数据库必须使用部分唯一索引保证每个用户最多一个 `in_progress` 练习会话。

### 6.2 `quiz_practice_session_question`

| 字段 | 类型 | 规则 |
|---|---|---|
| `id` | bigint | 会话题目快照 ID |
| `session_id` | bigint | 练习会话 |
| `question_id` | bigint | 当前题目引用，用于统计和状态提示 |
| `position` | int | 会话内从 1 开始的固定顺序 |
| `category_id` / `category_path` | bigint / jsonb | 分类快照 |
| `question_type` | enum | 题型快照 |
| `question_text` | varchar(1024) | 题干快照 |
| `options` | jsonb | 选项快照 |
| `correct_answer` | jsonb | 标准答案快照，仅服务端和作答结果可访问 |
| `explanation` | varchar(1024) | 解析快照，仅作答后或历史接口返回 |
| `question_lock_version` | int | 创建快照时题目版本 |

唯一约束：`(session_id, position)`、`(session_id, question_id)`。

### 6.3 普通练习选题

- 用户请求题数正常范围为 10 至 100。
- 小程序只展示 `10/20/50/100` 四个固定选项，不提供自由输入题量。
- 如果所选有效分类子树总题量不足 10，允许启动并使用全部可用题目。
- 如果请求数量大于可用题量，实际使用全部可用题目。
- 优先选择用户从未作答的题目，不足时再从已作答题目随机补足。
- “已作答”包括既有练习作答及已结算考试中的最终作答；`abandoned` 考试不参与。
- 同一会话不得出现重复题目。
- 不得把符合范围的全部题目 ID 加载到应用内再抽样；抽样实现必须满足容量和性能基线。

### 6.4 错题专项选题

- 只选择 `active` 且当前题目仍为有效 `published` 的错题。
- 按 `latest_wrong_at DESC, id DESC` 固定选择最近最多 20 道，不随机。
- 允许 1 至 20 题；不足 20 时使用全部。
- 错题专项与普通练习共用单一活动会话约束。

### 6.5 会话完成和放弃

- 每道快照题至少存在一次作答后，会话自动进入 `completed`。
- `completed` 后不得继续提交作答。
- 用户可以在完成前主动进入 `abandoned`。
- 放弃不会删除本轮作答，既有作答继续计入练习统计、自动打卡和错题规则。
- 会话没有自动过期时间。

## 7. 练习作答 `quiz_practice_attempt`

| 字段 | 类型 | 规则 |
|---|---|---|
| `id` | bigint | 主键 |
| `user_id` | bigint | 冗余用户引用，便于隔离和索引 |
| `session_id` | bigint | 必须为当前用户的活动练习会话 |
| `session_question_id` | bigint | 必须属于该会话 |
| `idempotency_key` | varchar(64) | 客户端生成；同一网络重试只产生一条记录 |
| `attempt_no` | int | 该会话题目的第几次作答，从 1 开始 |
| `is_first_attempt` | bool | `attempt_no=1` |
| `user_answer` | jsonb | 规范化后的字符串或字符串数组 |
| `is_correct` | bool | 使用会话快照判定 |
| `submitted_at` | timestamptz | 提交时间，不可修改 |

不变量：

- 作答记录不可更新或删除。
- 唯一约束至少包括 `(user_id, session_id, idempotency_key)` 和 `(session_question_id, attempt_no)`。
- 每次有效提交都创建独立记录；同一会话内重答不覆盖旧记录。
- 每道题每个会话只有首次作答进入练习正确率。
- 作答成功立即返回当时标准答案、解析和判定结果。
- 题目列表不能直接提交答案，所有普通作答必须关联练习会话。
- 允许自由跳题；服务端按固定顺序返回题目和未答状态。

## 8. 错题本 `quiz_wrong_item`

| 字段 | 类型 | 规则 |
|---|---|---|
| `id` | bigint | 主键 |
| `user_id` / `question_id` | bigint | 唯一用户题目组合 |
| `status` | enum | `active` / `cleared` |
| `first_wrong_at` | timestamptz | 首次答错时间 |
| `latest_wrong_at` | timestamptz | 最近答错时间 |
| `cleared_at` | timestamptz nullable | 最近清除时间 |
| `latest_wrong_snapshot` | jsonb | 最近一次答错时的题目快照，用于题目停用后的回退展示 |

规则：

- 练习会话首次作答错误时进入或重新激活错题。
- `completed` 或 `timed_out` 考试中的最终错误答案也进入或重新激活错题。
- 重新激活错题时保留 `cleared_at`，该字段始终表示最近一次清除时间。
- 同一练习会话内看到答案后的重答正确不能清除错题。
- 只有后续不同练习会话中该题的首次作答正确，才进入 `cleared`。
- 考试答对不清除错题。
- 错题列表优先展示当前题库内容；当前题目停用时展示 `latest_wrong_snapshot` 并标记不可用于新练习。
- 列表只返回题干和选项，不返回标准答案或解析。
- 不提供错题手动添加、手动删除或手动清除接口。

## 9. 收藏 `quiz_collection`

| 字段 | 类型 | 规则 |
|---|---|---|
| `id` | bigint | 主键 |
| `user_id` / `question_id` | bigint | 唯一用户题目组合 |
| `is_active` | bool | 收藏/取消收藏幂等切换 |
| `collected_at` | timestamptz | 最近收藏时间 |
| `removed_at` | timestamptz nullable | 最近取消时间 |

- 收藏与作答、错题状态完全独立。
- 重新收藏时保留 `removed_at`，该字段始终表示最近一次取消时间。
- 收藏题只能浏览，不能创建收藏专项练习。
- 收藏列表不返回答案或解析。
- 题目停用后保留收藏并标记“题目已停用”；用户可查看当前内容，但不能用于新练习或考试。

## 10. 自动打卡 `quiz_checkin`

| 字段 | 类型 | 规则 |
|---|---|---|
| `id` | bigint | 主键 |
| `user_id` | bigint | 用户 |
| `checkin_date` | date | `Asia/Shanghai` 自然日 |
| `questions_completed` | int | 当日练习作答数量，不含模拟考试 |
| `consecutive_days` | int | 当日结算后的连续天数 |
| `first_attempt_id` | bigint | 触发当天自动打卡的作答 |

- 唯一约束 `(user_id, checkin_date)`。
- 当天首次产生任一练习会话作答时自动创建打卡，包括普通练习和错题专项，不包括模拟考试。
- 不提供手动签到接口。
- 漏掉任一自然日后，下一次打卡的连续天数从 1 开始。
- 首版不发放积分。

## 11. 模拟考试

### 11.1 `quiz_exam`

| 字段 | 类型 | 规则 |
|---|---|---|
| `id` | bigint | 主键 |
| `user_id` | bigint | 用户 |
| `category_id` | bigint | 选题分类根节点 |
| `question_count` | int | 10 至 100 |
| `duration_seconds` | int | 服务端固定 3600 |
| `status` | enum | `in_progress` / `completed` / `timed_out` / `abandoned` |
| `started_at` | timestamptz | 服务端时间 |
| `deadline_at` | timestamptz | `started_at + 3600 seconds` |
| `submitted_at` | timestamptz nullable | 主动交卷时间 |
| `timed_out_at` | timestamptz nullable | 超时结算时间 |
| `abandoned_at` | timestamptz nullable | 主动放弃时间 |
| `correct_count` | int nullable | 结算后写入 |
| `wrong_count` | int nullable | 结算后写入 |
| `unanswered_count` | int nullable | 结算后写入 |
| `score` | numeric(5,1) nullable | `correct_count / question_count * 100` |
| `lock_version` | int | 并发保存和结算保护 |

数据库必须使用部分唯一索引保证每个用户最多一个 `in_progress` 考试，并使用检查约束保证 `deadline_at = started_at + 3600 seconds`。

### 11.2 `quiz_exam_question`

字段与练习题目快照一致，增加 `exam_id`。唯一约束：`(exam_id, position)`、`(exam_id, question_id)`。

### 11.3 `quiz_exam_answer`

| 字段 | 类型 | 规则 |
|---|---|---|
| `id` | bigint | 主键 |
| `exam_id` / `exam_question_id` | bigint | 唯一考试题目组合 |
| `user_answer` | jsonb | 当前最后保存答案 |
| `is_correct` | bool nullable | 仅结算时写入 |
| `saved_at` | timestamptz | 最近保存时间 |
| `lock_version` | int | 答案更新乐观锁 |

### 11.4 创建考试

- 用户选择有效分类和 10 至 100 道题。
- 小程序只展示 `10/20/50/100` 四个固定选项，不提供自由输入题量。
- 服务端递归使用该分类及后代分类中的有效已发布题目。
- 可用题量不足时拒绝创建，并返回当前最大可选数量。
- 同一考试无重复题目；不同考试允许重复抽到相同题目。
- 题目顺序随机后固定，选项始终保持 `A-D` 管理端顺序。
- 重复开始考试时返回现有活动考试，不创建第二条。
- 每天完成考试场次不设上限。

### 11.5 保存答案和结算

- 考试进行中允许自由跳题和反复修改答案，以最后保存值为准。
- 保存答案时服务端检查 `deadline_at`；已到期则先幂等结算，再拒绝修改。
- 用户可以在有未答题时主动交卷，未答题得 0 分并单独统计。
- 所有题等权，必须完全匹配标准答案才得分。
- 分数为百分制，四舍五入保留 1 位小数；不计算及格状态。
- 主动交卷和超时结算必须在单事务内完成考试状态、逐题判定、错题、个人统计和题目聚合事件写入。
- 后台任务定期认领到期考试；考试查询、保存和交卷接口同时执行懒结算兜底。
- `abandoned` 保留快照和已保存答案，但不判分、不进入统计、不返回答案或解析。
- 首版不实现切屏、截图、设备绑定等防作弊功能。

## 12. 统计

### 12.1 用户个人统计

练习和模拟考试必须分开返回，不得混算正确率。

实时汇总存入 `quiz_user_stats`，每个用户最多一条。该表至少保存练习总作答、首答、首答正确、已练题数、活动错题/收藏、打卡、考试场次、考试题数、正确/错误/未答、分数合计、最高分和最近分数。所有计数非负，练习首答正确数不得超过首答数，考试正确、错误与未答之和必须等于已结算考试总题数。

练习至少包含：

- `total_attempts`：全部不可变练习作答次数，包括同会话重答。
- `first_attempts`：每个会话题目的首次作答次数。
- `first_correct_attempts`：首次作答正确次数。
- `accuracy`：`first_correct_attempts / first_attempts * 100`。
- `answered_questions`：至少作答过一次的不同当前题目数量。
- `active_wrong_count`、`active_collection_count`。
- `checkin_days`、`consecutive_days`、当日练习题数。

考试至少包含：

- `completed_exam_count`、`timed_out_exam_count`。
- 已结算考试总题数、正确数、错误数、未答数。
- 平均分、最高分、最近一次分数。
- `abandoned` 不进入考试统计。

个人统计必须与作答或考试结算事务同步更新，接口读取后立即一致。

### 12.2 管理端题目聚合 `quiz_question_stats`

| 字段 | 含义 |
|---|---|
| `practice_first_attempts` | 普通练习和错题专项中的首次作答次数 |
| `practice_first_correct` | 练习首次作答正确次数 |
| `practice_first_accuracy` | 上述两者计算的正确率 |
| `exam_answers` | 已完成或超时考试中的已作答次数 |
| `exam_correct` | 考试正确次数 |
| `exam_accuracy` | 考试正确率 |

- 管理端只看聚合统计，不能查看具体用户逐题作答。
- 聚合允许最多 1 分钟延迟。
- 管理统计总览返回本次查询时间 `calculated_at` 和聚合水位 `aggregated_through`；单题明细每项返回 `aggregated_through`。页面必须明确展示聚合水位和最多 1 分钟延迟说明。
- 全局总览至少返回分类总数、各状态题目数、练习会话/首答、考试完成/超时、练习与考试正确率；单题明细支持分类、题型、状态、关键词和分页。
- 管理统计不提供用户级下钻，也不提供导出。

## 13. 完整练习历史

- 用户可分页查看全部练习作答。
- 支持分类、题型、正确状态和日期范围筛选。
- 每条记录返回作答时题目快照、用户答案、当时标准答案、解析、判定、会话及提交时间。
- 同一题同一会话内的重答全部可见。
- 当前题目状态可作为附加信息返回，但不得替换历史快照。

## 14. 管理端规则

### 14.1 权限

| 权限 | 能力 |
|---|---|
| `quiz:list` | 查看分类、题目、标准答案、解析、导入任务、页内错误明细、分类影响树、源文件/错误报告短签、聚合统计和审计日志 |
| `quiz:write` | 创建/编辑分类和题目、发布、批量发布、停用、恢复、删除草稿；与 `quiz:import` 共同用于确认导入创建缺失分类 |
| `quiz:import` | 创建 CSV/JSON 导入任务、取消等待分类确认的任务，并对基础设施失败的任务执行人工重试 |

- 不新增独立 `quiz:publish` 权限。
- 拥有 `quiz:write` 的管理员可以直接发布和停用。
- 超级管理员通过现有通配权限自动拥有上述能力，但任何题库操作都不额外要求超级管理员身份。
- 管理员不能查看具体用户的逐题作答内容。

### 14.2 乐观并发

- 分类和题目更新请求必须携带 `lock_version`。
- 数据库更新条件必须包含旧版本号。
- 版本冲突返回 HTTP 409、业务码 `40201`，不得静默覆盖。
- 批量发布和批量停用使用单一事务；任一对象不满足条件时整批不变，并返回逐项错误。
- 批量请求必须是管理员明确勾选的 1 至 100 个题目 ID，不支持“全部筛选结果”，不得接受重复 ID。

### 14.3 管理列表

题目列表支持：分类、题型、状态、题干关键词、分页。默认按 `updated_at DESC, id DESC`。

### 14.4 管理页面和交互

首版有五个逻辑页面：分类管理、题目管理、批量导入任务、题库聚合统计、题库审计日志。分类和题目可以复用同一题库布局，但必须具有稳定路由、权限门禁和刷新入口；任务监控是 OPS 辅助页，不替代这五页。

- 分类页按钮：新增、添加子分类、编辑、移动、启用、停用、删除。
- 题目页按钮：新增、编辑、发布、停用、恢复、删除草稿、批量发布、批量停用。
- 导入页按钮：CSV/JSON 模板下载、上传、刷新、页内错误明细、下载错误 JSON、源文件、查看分类影响树、确认/取消缺失分类创建和基础设施失败重试。
- 统计和审计只读，不提供编辑、删除或导出。
- 删除、停用和批量操作二次确认；分类移动前读取影响预览。
- HTTP 409 后刷新服务端数据，不自动重试或覆盖。
- 不提供批量删除草稿；题目编辑字段只包含分类、题型、题干、A-D 选项、答案和解析。

## 15. 导入任务 `quiz_import_job`

### 15.1 字段

| 字段 | 类型 | 规则 |
|---|---|---|
| `id` | bigint | 任务 ID |
| `admin_id` | bigint | 发起管理员 |
| `source_type` | enum | `csv` / `json` |

| `missing_category_count` / `affected_question_count` | int | 将新建分类节点数与受影响题数 |

### 15.2 导入规则

- CSV 和 JSON 使用同一套校验器。
- CSV 和 JSON 文件均最大 10 MB；两种格式单批最多 5,000 道题。
- 分类路径不超过三级；已存在的分类链必须有效。缺失分类不直接创建，而是进入 `awaiting_category_confirmation`。
- 所有行先校验并汇总错误，不边读边写题目表。
- 任一行存在格式、分类、题型、选项、答案、解析、长度或重复错误时进入 `validation_failed`，创建数量为 0。
- 校验全部通过后，在单一数据库事务中把全部题目创建为 `draft`。
- 分类影响树显示将新建、复用和阻断的节点及直接/子树题量；确认后 Worker 重新校验。影响变化时必须回到等待确认，不得沿用旧快照执行。
- 确认后的缺失分类与全部草稿题在同一 PostgreSQL 事务创建；任一错误全部回滚。
- 错误明细按任务和 `validation_version` 持久化，每页固定 50 条，可按字段筛选；不保存题干、选项、答案或原始值。
- 同一任务基础设施失败可幂等重试，不得重复创建题目。
- 人工重试仅允许 `failed`；`validation_failed` 必须修正内容后新建任务，`succeeded` 不得重试。
- 人工重试沿用原任务 ID 和唯一导入批次标识，重新进入 `queued`；执行前仍需重新校验状态和重试预算。
- 源文件和错误报告存入私有 OSS，使用不含文件名、题干或管理员信息的随机对象键。
- OSS 匿名访问必须拒绝；源文件和错误报告只通过最长 300 秒的短签访问，生成和下载均写审计。
- 源文件和报告在任务进入终态后保留 7 天并自动删除；清理失败可重试，删除后不得再签发地址。
- 首版不提供题库导出。

## 16. 审计 `quiz_admin_audit_log`

至少记录：

- 管理员、权限、请求 ID、IP、动作、对象类型、对象 ID、结果和时间。
- 创建、编辑、发布、批量发布、停用、恢复、删除草稿、分类移动、分类启停、导入创建/重试/完成。
- 后台任务认领/完成/失败/重试/清理、源文件和报告短签/下载，以及题库权限拒绝。
- 编辑操作保存所有变更字段的修改前值和修改后值，包括题干、选项、标准答案、解析、状态和分类。
- 批量操作保存目标 ID 集合、成功/失败结果和错误摘要。

审计日志永久保留，不提供更新或删除接口。
管理员审计记录引用的管理员不可物理删除；系统任务使用 `actor_type=system` 且 `admin_id` 为空。
查询支持管理员、动作、对象类型、对象 ID、结果、请求 ID 和起止时间；任何响应和日志都不得包含 Token、完整签名 URL、异常堆栈或未脱敏批量内容。审计不逐条记录用户练习作答或考试答案。

## 18. 限流与安全

- 题目列表：每用户每分钟 60 次。
- 练习作答和考试答案保存：每用户每分钟 120 次。
- 管理端普通写操作：每管理员每分钟 120 次。
- 管理端批量发布/停用：每管理员每分钟 30 次。
- 导入创建和人工重试：每管理员每分钟 10 次。
- OSS 源文件/报告短签：每管理员每分钟 60 次。
- 超限返回 HTTP 429，业务码冻结为 `40202`，且不得写入业务数据。
- 用户只能访问自己的会话、作答、收藏、错题、统计和考试；越权统一返回 404 或 403，不泄露资源存在性。
- 用户接口不得在考试进行中、考试放弃后、题目列表、错题本或收藏列表中返回标准答案和解析。
- 管理端标准答案仅对具备 `quiz:list` 权限的管理员返回。
- 普通应用日志不得记录完整导入文件、标准答案批量数据或用户全部作答正文。
- 管理限流按管理员 ID、用户限流按用户 ID，在生产多实例间通过 Redis 共享；Redis 不可用时生产就绪检查失败，不得静默退化为进程内额度。

## 19. 并发、事务和幂等

### 19.1 练习作答事务

单次作答在一个事务中完成：

1. 锁定并重新校验练习会话。
2. 校验会话题目归属和答案格式。
3. 以幂等键查询或创建不可变作答。
4. 首次作答时更新错题、个人统计和题目聚合事件。
5. 创建当天自动打卡或更新当天题数。
6. 检查全部题目是否已首次作答，并自动完成会话。

### 19.2 考试结算事务

单次结算在一个事务中完成：

1. `FOR UPDATE` 锁定考试。
2. 已结算状态直接返回既有结果。
3. 读取快照和最后保存答案并判分。
4. 写入逐题判定、总分和最终状态。
5. 更新错题、个人考试统计和题目聚合事件。

后台超时任务使用 `FOR UPDATE SKIP LOCKED` 认领，支持多 Worker、心跳和失败重试。

### 19.3 导入事务

- 校验阶段不修改分类或题目表。
- 导入阶段所有题目在一个事务中创建。
- 任务重试使用任务 ID 和唯一导入批次标识防止重复写入。

## 20. 数据保留和清理

| 数据 | 保留规则 |
|---|---|
| 题目、分类、练习/考试快照 | 账号有效期间及业务历史所需期间保留 |
| 练习作答、考试答案和成绩 | 账号有效期间永久保留 |
| 错题、收藏、打卡、个人统计 | 账号有效期间保留 |
| 管理审计 | 永久保留 |
| 导入源文件和错误报告 | 进入终态后保留 7 天删除；运行中任务不清理，失败删除可重试 |
| 旧题库数据 | 新版迁移执行时全部清空，不迁移 |

## 21. 迁移基线

- 新增一条 Alembic 迁移，删除旧题库相关表并按本文重新创建。
- 不修改任何已存在的历史迁移。
- 升级前必须完成并验证数据库备份。
- 降级只恢复旧表结构，不尝试恢复已删除数据。
- 新迁移只能操作题库相关表、索引、约束和枚举，生成 SQL 中不得出现 `banner`、`zone` 或其他非题库表的 DDL。
- 旧题库分类、题目、作答、错题、收藏、打卡和考试数据全部丢弃，按新模型重新导入。

## 22. 性能与可观测性

| 接口类型 | 目标 |
|---|---:|
| 题目列表与统计 | P95 不超过 500 ms |
| 练习作答、考试答案保存 | P95 不超过 300 ms |
| 练习或考试创建 | P95 不超过 1 s |

- 性能验收使用 10 万道题、10 万用户、500 并发活跃用户基线。
- 会话选题不得把全部候选 ID 拉到应用内再调用 `random.sample`。
- 后台考试结算、导入和聚合任务必须记录状态、进度、心跳、重试次数和安全错误摘要。
- 对活动会话重复创建、作答幂等冲突、考试重复交卷、超时结算失败、导入失败和聚合延迟建立指标和告警。
- 生产拆出独立 `quiz-worker`，统一处理导入、考试超时、题目统计聚合和 OSS 清理；Web 只处理 HTTP 请求，不启动这些后台循环。
- 监控至少包含队列深度、任务耗时/失败/卡死、考试超时结算延迟、统计滞后、OSS 清理积压、API P95/错误率/429 和 PostgreSQL/Redis/OSS 就绪状态。
- PostgreSQL 每日备份，RPO 不超过 24 小时、RTO 不超过 4 小时；破坏性迁移前额外备份，并至少每季度执行一次恢复演练。

## 23. 三端页面和客户端行为

### 23.1 匿名与登录边界

- 小程序题库首页的有效分类树允许匿名加载；首页个人统计、题目浏览、练习、错题、收藏、打卡和考试均要求微信登录。
- 401 时清除失效访问令牌并进入统一重登；刷新令牌成功后恢复原目标页和服务端活动会话。
- 允许同一账号多设备登录，服务端会话、答案和版本始终权威。

### 23.2 练习客户端

- 进入练习前先读取当前活动会话；存在时恢复，不存在时才创建。
- 允许自由跳题；选择选项本身不提交，用户点击“提交答案”后才调用作答接口。
- 提交成功立即展示本次判定、标准答案和解析，并允许再次提交形成不可变重答记录。
- 每次用户意图生成一个持久化 `idempotency_key`，网络超时重试必须复用，收到确定响应后才能生成下一把键。
- 所有题首次提交后由服务端自动完成；客户端不得仅凭本地题数修改会话状态。

### 23.3 考试客户端

- 进入考试前读取当前进行中考试；存在时恢复，不存在时才创建。
- 剩余时间由服务端 `deadline_at` 计算；退出、锁屏、断网或切后台不暂停。
- 选项变化立即保存但不判分；保存携带上次服务端版本，409 时重新读取详情并提示冲突，不静默覆盖。
- 交卷前显示未答数量并二次确认；只有 `completed/timed_out` 展示成绩、答案和解析。
- `in_progress/abandoned` 页面、缓存和日志均不得保留或展示标准答案、解析或成绩。

### 23.4 本地缓存和发布

- 本地只保存 Token、活动练习/考试 ID、答案保存版本及必要临时 UI 状态，不缓存整套标准答案、解析或历史详情。
- 退出登录、注销账号和切换账号时清空全部题库缓存；换机和重装后通过服务端恢复。
- Backend、Admin 和 Platform 使用同一契约版本联合发布；旧 API 不提供重定向、字段别名、双写或客户端回退。

## 24. 首版明确不做

- 正式考试、防作弊、切屏或设备行为采集。
- 题目版本链或历史题库内容回滚。
- 题目难度、权重、标签、来源年份和试卷模板。
- 多选题部分得分。
- 图片、富文本、音视频题目。
- 收藏专项练习。
- 手动错题维护和手动签到。
- 题库导出。
- 旧题库数据迁移和旧 API 兼容。
