> 日期：2026-08-06

## 已完成

- 新增机器可读 OpenAPI 契约注册表，共 43 个新端点、14 个明确删除端点。
- 新增用户端和管理端严格 Pydantic Schema；考试按 `in_progress`、`abandoned`、`completed/timed_out` 分离响应类型。
- 新增 Alembic `quiz001`，删除 5 张旧题库表并创建 15 张新表。
- 有旧数据时，升级必须提供 `quiz_backup_ref` 或 `QUIZ_DESTRUCTIVE_MIGRATION_BACKUP_REF`；否则迁移直接终止。
- 降级只恢复 5 张旧空表，不恢复删除的数据；有新数据时同样要求独立降级备份引用。
- 数据库约束允许恢复题目、重新激活错题和重新收藏时保留最近历史时间，并强制考试截止时间等于开始时间加 3600 秒。
- 新增统一题型、选项、答案、题干和完全匹配判分规则。
- 新增题库运行配置和可注册后台任务循环；生产启动校验 Redis 和私有阿里云 OSS。

## 迁移命令

旧题库含数据时：

```bash
python -m alembic -x quiz_backup_ref=<已验证备份引用> upgrade head
```

有新题库数据时降级：

```bash
python -m alembic -x quiz_downgrade_backup_ref=<已验证备份引用> downgrade rsh001
```

降级后的旧题库表为空，这是冻结接受结果。

## 外部阻塞

当前执行沙箱禁止创建和连接 TCP/Unix Socket。本机 PostgreSQL 3306 和一次性 PostgreSQL 17 集群均无法建立连接，因此真实 `upgrade -> downgrade -> upgrade` 用例在本轮被跳过。解除方式是提供允许 Socket 的运行环境并设置 `TEST_DATABASE_URL_SYNC`；测试会自行创建和删除随机命名的隔离数据库，不会迁移配置中的业务库。
