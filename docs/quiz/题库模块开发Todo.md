## 1. 交付目标

首版必须完整跑通：

1. 管理员创建三级以内分类，创建草稿题目并发布。
2. 管理员通过 CSV/JSON 后台任务原子导入最多 5,000 道草稿题。
3. 登录用户浏览题目，创建唯一活动练习会话并提交不可变作答。
4. 系统自动维护错题本、收藏、打卡、练习历史和个人统计。
5. 用户创建唯一活动模拟考试，60 分钟内保存答案、主动交卷或由服务端超时结算。
6. 已完成或超时考试展示冻结答案和解析；进行中或放弃考试不泄露答案。
7. 管理端查看不包含个人身份的题目聚合统计和永久审计记录。
8. 真实 PostgreSQL、HTTP、并发、超时和容量测试全部通过。

完成定义不是“接口存在”，而是新版迁移、状态机、事务、幂等、答案隔离、后台任务和性能门槛都有可执行证据。

## 2. 当前基线

### 2.1 已有能力

- 用户端已有分类、题目、单题提交、错题、收藏、打卡、统计和模拟考试路由。
- 管理端已有分类/题目 CRUD、CSV/JSON 导入和三项题库权限。
- 题型目前支持单选、多选、判断。
- 当前相关单元测试命令结果为 `52 passed`。

### 2.2 已确认缺口

| 问题 | 现状 |
|---|---|
| 数据模型 | `quiz_record` 同时承担作答、错题和收藏，无法保存每次作答 |
| 历史一致性 | 练习和考试没有完整题目快照，题目修改会影响历史展示或判分 |
| 答案安全 | 进行中考试详情可以返回标准答案和解析 |
| 考试事务 | 逐题更新中多次提交事务，整场结算不是原子操作 |
| 超时 | 没有可靠的服务端后台超时结算闭环 |
| 唯一会话 | 用户可以创建多场进行中考试；没有练习会话模型 |
| 分类 | 可形成循环；三级以上题数和进度汇总错误 |
| 题目校验 | 选项和正确答案为任意 JSON/字符串，题型间缺少一致性校验 |
| 批量删除 | 返回查询到的数量，不是实际删除数量 |
| 导入 | 可部分成功、缺少统一原子校验、JSON 数量无上限、没有任务和报告保留机制 |
| 迁移 | `defd8000045e` 创建考试表时包含删除 `banner` 等非题库 DDL |
| 测试证据 | 现有 PostgreSQL 题库集成测试仅 2 项，当前因未设置 `TEST_DATABASE_URL` 跳过 |
| 文档 | `docs/接口列表.md` 对 DB 集成和 HTTP 冒烟完成度存在过度声明 |

## 10. 必测业务矩阵

### 10.1 题目和分类

- 分类深度 1/2/3 成功，深度 4、自引用和循环失败。
- 停用父分类后，子树题目不进入分类树、列表、练习和考试。
- 公开分类计数包含全部有效后代，并隐藏空分支。
- 单选 2 项、5 项失败；3/4 项成功。
- 多选不是 4 项、答案少于 2 项、未知选项失败；四项全对成功。
- 判断选项不是固定 A/B 或正确答案不是 A/B 时失败。
- 草稿解析可空，发布解析必填。
- 同分类规范化题干重复失败，不同分类允许。
- 发布题编辑后保持发布；旧会话快照不变化。

### 10.2 练习

- 一个用户并发创建普通/错题专项时只保留一个活动会话。
- 普通练习优先未作答，题量不足时正确缩减，同会话不重复。
- 错题专项按最近时间取最多 20 题，不随机。
- 同一幂等键重复提交只产生一条作答。
- 同会话重答产生多条记录，但只有首次作答影响正确率和错题清除。
- 后续不同会话首次答对清除错题；同会话看答案后答对不清除。
- 最后一题首次作答后会话自动完成；完成后拒绝新作答。
- 放弃后作答、错题、打卡和统计仍保留。
- 题目列表、错题本和收藏列表均不出现 `correct_answer` 或 `explanation`。

### 10.3 模拟考试

- 开始考试固定 60 分钟，题数 10-100；题量不足返回最大可选数。
- 重复开始返回当前考试；放弃或结算后可新建。
- 进行中自由保存和修改答案，选项顺序不变化。
- 主动交卷、超时 Worker 和查询懒结算竞争时只产生一个最终结果。
- 多选完全匹配才得分；未答和错误分开统计；分数保留 1 位小数。
- `completed/timed_out` 展示答案和解析；`in_progress/abandoned` 永不展示。
- 放弃考试不进入统计、不产生考试判定，也不能借此获取答案。

### 10.4 导入和审计

- 10 MB、5,000 题边界成功；超限在业务写入前失败。
- 缺失、停用、越级分类路径导致整批 `validation_failed`。
- 任一行错误时创建数量必须为 0，报告包含全部行错误。
- Worker 重试同一任务不重复创建题目。
- 源文件和报告只能通过短签访问，7 天后清理。
- 所有管理写操作均有不可修改审计及字段前后值。
