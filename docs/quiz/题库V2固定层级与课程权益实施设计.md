# 题库 V2：固定层级、全量练习与课程权益实施设计

状态：批次 A–F 代码与本地门禁已完成，待部署验收
冻结日期：2026-08-13
适用仓库：Backend、Admin、Platform

> 本文是题库 V2 的现行业务与实施基线。旧《题库模块全链路开发 Todo》中的递归三级分类、匿名浏览和练习题量选择等规则已废止。

## 1. 目标与边界

题库 V2 将原有可递归分类模型替换为固定语义模型：

```text
QuizLibrary（题库，内容与权益边界）
└── QuizModule（模块）
    └── QuizKnowledgePoint（知识点）
        └── QuizQuestion（逻辑题目）
            └── QuizQuestionRevision（不可变内容版本）
```

- 只有知识点可以挂题；题库和模块不能直接挂题。
- 一道逻辑题只属于一个题库和一个知识点。
- 标签仅用于搜索和筛选，不参与归属、题池或权益计算。
- 本轮只实现免费题库和课程购买赠送题库，不实现题库单独售卖。
- 支付意图、延迟回调、退款编排属于支付模块；题库只消费已结算的课程权益结果。

## 2. 稳定标识与唯一性

- 题库拥有系统生成的 `library_code`，全局唯一、创建后不可修改、删除后不可复用。
- 题库名称全局唯一；模块名称在题库内唯一；知识点名称在模块内唯一。
- 同一题库内规范化题干唯一，不同题库允许相同题干。
- 名称和题干在逻辑删除后的 7 天撤销期内保留占用；撤销期后可由新 ID 复用。
- 所有历史、审计、迁移映射和权益关联稳定 ID，不使用可变名称作为关联键。

## 3. 状态机

### 3.1 题库

```text
draft -> published <-> suspended -> archived -> deleted
```

- `archived` 为不可恢复的业务终态，但可整体逻辑删除。
- `deleted` 在 7 天内可撤销为 `archived`，不会自动发布。
- 发布必须具备封面、简介、访问模式以及至少一条有效的“模块 → 知识点 → 已发布题目”路径。
- `course_entitlement` 题库发布后未绑定课程时仍不对用户可见。
- 已发布题库不得因普通操作变成零道可用已发布题；紧急清空必须原子停用题库。

### 3.2 模块与知识点

```text
active <-> disabled -> deleted
```

- 父级停用只屏蔽子树，不改写子项自身状态。
- 恢复父级后，子项仍按自身状态生效。
- 删除严格自底向上，不提供级联删除。
- 删除后 7 天内可撤销为 `disabled`。

### 3.3 题目与版本

- 逻辑题状态为 `draft / published / disabled / deleted`。
- 发布题目的编辑生成唯一待发布版本，不覆盖当前已发布版本。
- 发布版本只切换未来会话；已开始练习、考试和历史记录继续使用冻结版本。
- 停用题可以编辑和发布新版本，但发布版本不会自动重新启用题目。
- 已发布题必须先停用后逻辑删除；从未发布且无引用的草稿可直接清理。
- 删除后 7 天内可撤销为 `disabled`。

## 4. 课程权益

题库访问模式：

```text
access_mode_pending / free / course_entitlement
```

- 用户必须登录才能使用小程序功能。
- `free` 题库不创建个人权益行。
- 课程与题库多对多；一门课程可以不赠送题库，也可以赠送多个题库。
- 首版按 `course_id` 绑定，不区分 SKU 或课程规格。
- 一项有效权益开放整库的练习、错题复习、当前和未来内容及考试。
- 目录只返回免费题库和当前用户有有效权益的课程题库；无权益和越权直达统一按 `404 quiz_library_not_found` 处理，不在题库内导购。
- 课程详情实时读取题库当前展示资料；订单结算时冻结题库 ID、编码、名称、封面和简介快照。
- 课程结算与权益发放使用唯一幂等键 `order_id + library_id`；退款或课程权益撤销只撤销对应来源，其他有效来源仍可保留访问。

## 5. 练习

- 有效练习范围为题库、模块和知识点，范围标识为 `scope_type + scope_id`。
- 普通练习包含范围内全部当前可用已发布题，不再接收题量选择。
- 100 题以内直接开始；超过 100 题只显示数量、预计耗时和 7 天有效期，不允许缩减题量。
- 服务端冻结题目 ID、顺序、版本及路径快照；接口仅返回当前题与小型预取窗口。
- 同一用户、同一范围、同一模式只允许一个进行中会话；父子范围互不冲突。
- 会话自最后一次成功作答起 7 天滚动有效；题库停用或权益临时失效期间暂停倒计时。
- 发现未完成会话时，前端明确提供“继续练习”和“重新开始”；重新开始会放弃旧会话并创建当前快照。
- 老版本限量会话标记为 `legacy_limited`，保留原题量和顺序；重新开始时创建 V2 全量会话。

## 6. 导入

- 创建任务时必须选择一个未归档题库。
- 文件层级固定为模块、知识点和题目，不能创建题库，也不能把题挂到模块。
- 缺少模块或知识点时进入 `awaiting_category_confirmation`（UI 文案“等待分类确认”）。
- 管理员查看影响树并确认后，在同一事务中创建结构和全部草稿题；任一错误整批回滚。
- 停用结构不自动恢复，也不作为缺失结构重复创建。
- 首版导入只新增：文件内重复或与题库现有规范化题干重复均汇总为错误，并整批不落库。

## 7. 旧数据迁移

- 一级旧分类映射为题库，二级映射为模块，三级映射为知识点。
- 一级直接挂题迁入系统节点 `待整理（模块） → 未分类（知识点）`。
- 二级直接挂题迁入该模块下的系统 `未分类（知识点）`。
- 异常层级、父级缺失、循环或无效归属不猜测修复；相关题目进入系统待整理节点并写入迁移问题报告。
- 管理员完成归类或删除后，通过题库“迁移问题”抽屉执行重新检查；题目已进入普通模块/知识点或已删除时关闭对应问题，仍在系统节点及重复题干问题继续阻断发布。发布题库前执行同一套复检。
- 系统节点使用内部标识，不依赖中文名称判断。
- 迁移后的题库全部为 `draft + access_mode_pending` 且默认关闭 V2 用户入口。
- 旧分类、新实体和原始路径之间的映射永久保留。
- 迁移必须幂等、事务化、可报告；在 V2 启用前不删除旧表和字段。

## 8. 管理后台信息架构

- `/admin/quiz/libraries`：题库资料、访问模式、生命周期、逐库启用及课程绑定。
- 题库列表的迁移问题数量可打开详情抽屉，展示旧对象、原路径、处理方式，并提供前往内容工作台和重新检查入口。
- `/admin/quiz/questions`：内容工作台。顶部选择题库，左侧固定“模块 → 知识点”树，右侧题目。
- 左树直接完成模块、知识点的新增、编辑、排序、移动、停用和删除，不再保留独立分类管理页。
- 点击模块可查看整个模块题目；手工新增题目必须选择知识点。
- 导入任务只选择题库，文件每行携带模块/知识点路径；缺失结构必须先进入影响树确认，不允许将题目直接挂到题库或模块。
- 旧分类管理路由重定向到内容工作台。

## 9. 稳定错误契约

错误响应包含 `code`、`message`、`detail.reason` 和响应头/正文中的 `request_id`。客户端只按稳定原因码决策：

| HTTP | `detail.reason` | 含义 |
|---:|---|---|
| 404 | `quiz_library_not_found` | 无权益、不可见或资源不存在 |
| 423 | `quiz_library_suspended` | 题库临时停用 |
| 423 | `quiz_entitlement_inactive` | 权益临时失效 |
| 410 | `practice_session_expired` | 练习会话超过有效期 |
| 410 | `practice_session_terminated` | 归档或删除导致永久终止 |
| 409 | `quiz_version_conflict` | 乐观锁或状态冲突 |
| 429 | `quiz_rate_limited` | 分级限流 |

## 10. 上线与回滚

1. 先部署扩展式数据库迁移和迁移报告能力，不删除旧结构。
2. 完成逐库访问模式确认、待整理清理、课程绑定和权益回填核对。
3. 通过题库级功能开关逐库启用 V2。
4. V2 是启用后的唯一写入模型；旧接口只做新模型适配，不双写业务状态。
5. 兼容期为 7 天；旧客户端只可续做既有 `legacy_limited` 会话。
6. 异常时关闭对应题库入口和新写操作，应用可回滚；已产生的 V2 数据不反向写回旧模型，修复后继续前向迁移。
7. 核验结束后另行删除兼容接口和旧结构。
