# 题库访问模式切换修复（2026-11-04）

本次修复题库价格未保存、免费模式无法通过专用接口转入付费模式，以及弹窗版本冲突后继续提交旧版本的问题。

## 业务行为

- `paid` 模式保留用于积分商城兑换题库。课程和题库的现金购买接口继续保持既有关闭规则；实际兑换积分在积分商城商品中维护。
- 新建、编辑和转换接口均支持 `price_cents`，按分保存0至2147483647的整数；切入付费模式必须有正数价格。管理端详情、列表和保存响应返回实际价格，修改名称等展示资料不重置原价格。
- 专用转换接口允许从待确认、免费、课程权益及激活码模式转入付费模式；价格与模式在同一事务保存，失败不消耗版本。审计包含价格变化。
- 付费模式的用户目录、练习准入和练习会话同步识别有效权益。积分兑换后可练习，权益撤销后按既有机制暂停会话并拒绝继续答题。
- 免费、课程权益、激活码的其他访问校验继续保留。课程权益题库启用用户入口前仍需有效课程绑定；缺少绑定时提示先关闭入口、切换模式并完成绑定，再重新开启。

## 后台交互

- 编辑表单提交并校验价格；转换弹窗支持填写价格，在本地校验通过后才进行二次验证和提交。
- 保存和转换均防止连续点击产生重复请求。
- 版本冲突时加载最新题库资料及版本，要求管理员核对后重新修改或选择目标模式。最新资料无法加载或题库已不存在时关闭旧弹窗，避免继续提交失效版本。
- 转换业务错误显示在弹窗内，便于按具体原因处理。

## 验证与发布

本地验证：Backend 34项通过，包含真实PostgreSQL的价格保存、转换失败回滚、版本冲突、积分权益访问及撤销回归；Admin 17项通过，覆盖价格请求、表单转换、重复点击和冲突后使用新版本。Admin TypeScript与生产构建通过。

本次不新增数据库迁移，运行环境须已完成题库价格和访问模式相关既有迁移。需先更新Backend、再更新Admin；新Admin提交价格字段需要配套后端识别。已有题库、积分商品及权益不批量改写。本次仅上传代码，线上实际报错与发布后的功能仍需由部署方复测。
