## 认证

### POST /api/auth/login — 微信 code 登录，返回 JWT token

#### 请求头

| Header | 值 | 必填 | 说明 |
|--------|------|------|------|
| Content-Type | application/json | 是 | |

#### 路径参数

无

#### 查询参数

无

#### 请求体

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| code | string | 是 | — | 小程序调用 `wx.login()` 获取的临时凭证，5 分钟有效，一次性 |

示例：

```json
{
  "code": "081aBcDeFgHiJkLmN0oP1qRsT"
}
```

#### 响应体

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 |
| message | string | ok |
| data.access_token | string | JWT，接口鉴权用，有效期 2 小时 |
| data.refresh_token | string | 用于无感刷新 access_token，有效期 30 天 |
| data.expires_in | int | access_token 有效时长，单位秒 |
| data.user.id | int | 用户 ID |
| data.user.openid | string | 微信 openid |
| data.user.phone | string\|null | 手机号（未绑定则为 null） |
| data.user.created_at | string | 注册时间，ISO 8601 |

示例：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "access_token": "eyJhbGciOiJIUzI1NiIs...",
    "refresh_token": "rft_abc123def456...",
    "expires_in": 7200,
    "user": {
      "id": 1,
      "openid": "oABC123xyz...",
      "phone": null,
      "created_at": "2026-05-17T10:30:00+08:00"
    }
  }
}
```

#### 错误码

| code | 说明 |
|------|------|
| 40001 | 参数校验失败（code 字段缺失或为空，详见 detail 字段） |
| 40100 | 该账号已注销，30 天内不可重新注册 |
| 40100 | 账号已注销，如需恢复请联系客服 |
| 50000 | 微信 code2session 失败或服务器内部错误 |

#### 示例

```bash
curl -X POST "https://api.example.com/api/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"code": "081aBcDeFgHiJkLmN0oP1qRsT"}'
```

### POST /api/auth/refresh — 刷新 access_token

#### 请求头

| Header | 值 | 必填 | 说明 |
|--------|------|------|------|
| Content-Type | application/json | 是 | |

#### 路径参数

无

#### 查询参数

无

#### 请求体

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| refresh_token | string | 是 | — | 登录或上次刷新时下发的 refresh_token |

示例：

```json
{
  "refresh_token": "rft_abc123def456..."
}
```

#### 响应体

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 |
| message | string | ok |
| data.access_token | string | 新签发的 JWT，有效期 2 小时 |
| data.refresh_token | string | 新签发的 refresh_token，旧 token 立即失效（轮换） |
| data.expires_in | int | access_token 有效时长，单位秒 |

示例：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "access_token": "eyJhbGciOiJIUzI1NiIs...",
    "refresh_token": "rft_new789ghi012...",
    "expires_in": 7200
  }
}
```

#### 错误码

| code | 说明 |
|------|------|
| 40001 | 参数校验失败（refresh_token 字段缺失或为空） |
| 40100 | refresh_token 无效或已过期 |
| 40100 | 账号不存在或已注销 |

#### 示例

```bash
curl -X POST "https://api.example.com/api/auth/refresh" \
  -H "Content-Type: application/json" \
  -d '{"refresh_token": "rft_abc123def456..."}'
```

### POST /api/user/identity — 提交实名认证信息

#### 请求头

| Header | 值 | 必填 | 说明 |
|--------|------|------|------|
| Authorization | Bearer \<jwt_token\> | 是 | 登录后获取的 Token |
| Content-Type | application/json | 是 | |

#### 路径参数

无

#### 查询参数

无

#### 请求体

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| user_type | string | 是 | — | 用户类型：`student` / `enterprise` |
| real_name | string | 是 | — | 真实姓名 |
| id_card_number | string | 是 | — | 18 位身份证号，校验位须正确 |
| id_card_front_oss | string\|null | 否 | null | 身份证人像面 OSS key |
| id_card_back_oss | string\|null | 否 | null | 身份证国徽面 OSS key |
| student_card_oss | string\|null | 否 | null | 学生证 OSS key，student 用户必传 |

示例：

```json
{
  "user_type": "student",
  "real_name": "张三",
  "id_card_number": "320102199001011234",
  "id_card_front_oss": null,
  "id_card_back_oss": null,
  "student_card_oss": "oss/student_card/123.png"
}
```

#### 响应体

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 |
| message | string | ok |
| data.user_type | string | `student` / `enterprise` |
| data.real_name | string | 真实姓名 |
| data.id_card_number | string | 身份证号，脱敏返回（前 4 + 后 4，中间掩码） |
| data.id_card_front_oss | string\|null | 身份证人像面 OSS key |
| data.id_card_back_oss | string\|null | 身份证国徽面 OSS key |
| data.student_card_oss | string\|null | 学生证 OSS key |
| data.status | string | 审核状态：`pending` / `verified` / `rejected`（提交即 `verified`） |
| data.verified_at | string\|null | 审核通过时间，ISO 8601 |
| data.created_at | string | 创建时间，ISO 8601 |

示例：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "user_type": "student",
    "real_name": "张三",
    "id_card_number": "3201**********1234",
    "id_card_front_oss": null,
    "id_card_back_oss": null,
    "student_card_oss": "oss/student_card/123.png",
    "status": "verified",
    "verified_at": "2026-05-17T15:00:00+08:00",
    "created_at": "2026-05-17T15:00:00+08:00"
  }
}
```

#### 错误码

| code | 说明 |
|------|------|
| 40001 | 参数校验失败（必填字段缺失） |
| 40001 | 身份证号格式不合法（长度 / 校验位） |
| 40001 | 学生用户必须上传学生证 |
| 40100 | 未登录或 Token 已过期 |
| 40100 | 账号已注销 |
| 40200 | 实名信息最多修改 3 次，已达上限 |
| 40300 | 用户不存在 |

#### 示例

```bash
curl -X POST "https://api.example.com/api/user/identity" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..." \
  -H "Content-Type: application/json" \
  -d '{"user_type":"student","real_name":"张三","id_card_number":"320102199001011234","student_card_oss":"oss/sc/123.png"}'
```

## 订单

### 订单库存规则

第一期订单库存采用认证报名名额模型：

- 库存粒度为 `cert_type` 级别的认证报名名额。
- 库存记录使用 `inventory_type = 'certification'`。
- 库存记录的 `ref_code` 与订单请求中的 `cert_type` 一一对应。
- 创建订单时按 `inventory_type = 'certification' AND ref_code = cert_type` 原子锁定库存名额（`UPDATE ... WHERE available_quota >= 1`），库存不足时拒绝创建订单。
- 订单创建后进入 `pending` 状态，`expires_at` 默认 30 分钟后过期。
- 过期订单将被超时关闭（`pending → closed`），自动释放锁定的库存。
- 发起支付时如订单已过期，自动关闭并释放库存后返回 40200 错误。
- 发起支付时如订单距离过期不足 60 秒，返回 40200 错误，提示重新下单。
- 支付成功回调将库存从 `locked` 转为 `sold`（确认成交），重复回调不重复确认（幂等）。
- 第一期退款默认不恢复库存；后续可由配置决定是否恢复可售名额。
- 后续如需课程批次或考试场次库存，可扩展新的 `inventory_type`，不改变订单支付库存主流程。

```
data: {"done": true, "session_id": "<session_id>", "reply": "<完整回复文本>"}
```

异常时：


示例流：

```
data: {"chunk": "您好", "session_id": "a1b2c3d4-..."}

data: {"chunk": "，", "session_id": "a1b2c3d4-..."}

data: {"chunk": "人工", "session_id": "a1b2c3d4-..."}

data: {"chunk": "客服", "session_id": "a1b2c3d4-..."}

data: {"chunk": "正在", "session_id": "a1b2c3d4-..."}

data: {"chunk": "赶来", "session_id": "a1b2c3d4-..."}

data: {"chunk": "，", "session_id": "a1b2c3d4-..."}

data: {"chunk": "请稍候", "session_id": "a1b2c3d4-..."}

data: {"chunk": "...", "session_id": "a1b2c3d4-..."}

data: {"done": true, "session_id": "a1b2c3d4-...", "reply": "请稍候，客服服务正在接入..."}
```

> 流内异常通过 `{"error": "..."}` 事件推送，不走 JSON 错误响应。

#### 请求头

| Header | 值 | 必填 | 说明 |
|--------|------|------|------|
| Authorization | Bearer \<jwt_token\> | 是 | 登录后获取的 Token |

#### 路径参数

无

#### 查询参数

无

#### 请求体

无

#### 响应体

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 |
| message | string | ok |
| data.id | int\|null | 打卡记录 ID，未打卡时为 null |
| data.checkin_date | string | 打卡日期 |
| data.checked_in | bool | 当天是否已打卡 |
| data.questions_completed | int | 当天完成题数 |
| data.consecutive_days | int | 连续打卡天数 |

示例：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 10,
    "checkin_date": "2026-05-17",
    "checked_in": true,
    "questions_completed": 20,
    "consecutive_days": 7
  }
}
```

#### 错误码

| code | 说明 |
|------|------|
| 40100 | 未登录或 Token 已过期 |
| 50000 | 服务器内部错误 |

#### 示例

```bash
curl "https://api.example.com/api/quiz/checkin" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..."
```

### POST /api/quiz/checkin — 打卡签到

#### 请求头

| Header | 值 | 必填 | 说明 |
|--------|------|------|------|
| Authorization | Bearer \<jwt_token\> | 是 | 登录后获取的 Token |
| Content-Type | application/json | 是 | |

#### 路径参数

无

#### 查询参数

无

#### 请求体

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| questions_completed | int | 否 | 0 | 当天完成题数 |

示例：

```json
{
  "questions_completed": 20
}
```

#### 响应体

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 |
| message | string | ok |
| data.id | int\|null | 打卡记录 ID |
| data.checkin_date | string | 打卡日期 |
| data.checked_in | bool | 当天是否已打卡 |
| data.questions_completed | int | 当天完成题数 |
| data.consecutive_days | int | 连续打卡天数（基于昨天签到记录自动计算） |

> 重复签到幂等，返回已有记录。

示例：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 10,
    "checkin_date": "2026-05-17",
    "checked_in": true,
    "questions_completed": 20,
    "consecutive_days": 7
  }
}
```

#### 错误码

| code | 说明 |
|------|------|
| 40100 | 未登录或 Token 已过期 |
| 50000 | 服务器内部错误 |

#### 示例

```bash
curl -X POST "https://api.example.com/api/quiz/checkin" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..." \
  -H "Content-Type: application/json" \
  -d '{"questions_completed": 20}'
```

### GET /api/points/history — 积分获取/消耗记录

#### 请求头

| Header | 值 | 必填 | 说明 |
|--------|------|------|------|
| Authorization | Bearer \<jwt_token\> | 是 | 登录后获取的 Token |

#### 路径参数

无

#### 查询参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| page | int | 否 | 1 | 页码，从 1 开始 |
| page_size | int | 否 | 20 | 每页数量，最大 100 |

#### 请求体

无

#### 响应体

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 |
| message | string | ok |
| data.items[].id | int | 积分流水 ID |
| data.items[].action_type | string | 积分动作类型 |
| data.items[].amount | int | 积分变动值，正数为获得，负数为消耗 |
| data.items[].balance_after | int | 变动后积分余额 |
| data.items[].description | string\|null | 流水说明 |
| data.items[].source_type | string\|null | 幂等来源类型 |
| data.items[].source_id | string\|null | 幂等来源 ID |
| data.items[].created_at | string | 创建时间，ISO 8601 |
| data.total | int | 流水总数 |
| data.page | int | 当前页码 |
| data.page_size | int | 每页数量 |

示例：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "items": [
      {
        "id": 1,
        "action_type": "claim",
        "amount": 10,
        "balance_after": 10,
        "description": "每日签到领取",
        "source_type": "daily_checkin",
        "source_id": "2026-05-17_1",
        "created_at": "2026-05-17T10:30:00+08:00"
      },
      {
        "id": 2,
        "action_type": "redeem",
        "amount": -50,
        "balance_after": -40,
        "description": "考试折扣兑换",
        "source_type": "redeem",
        "source_id": null,
        "created_at": "2026-05-17T10:35:00+08:00"
      }
    ],
    "total": 2,
    "page": 1,
    "page_size": 20
  }
}
```

#### 错误码

| code | 说明 |
|------|------|
| 40100 | 未登录或 Token 已过期 |
| 50000 | 服务器内部错误 |

#### 示例

```bash
curl "https://api.example.com/api/points/history?page=1&page_size=20" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..."
```

### POST /api/points/claim — 领取积分

#### 请求头

| Header | 值 | 必填 | 说明 |
|--------|------|------|------|
| Authorization | Bearer \<jwt_token\> | 是 | 登录后获取的 Token |
| Content-Type | application/json | 是 | |

#### 路径参数

无

#### 查询参数

无

#### 请求体

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| scene | string | 是 | — | 领取场景：`daily_checkin` / `quiz_task` / `new_user` / `activity` |
| source_id | string\|null | 否 | null | 领取周期或活动 ID，为空时按场景自动生成 |
| description | string\|null | 否 | null | 领取说明 |

示例：

```json
{
  "scene": "daily_checkin",
  "source_id": null,
  "description": "每日签到领取积分"
}
```

#### 响应体

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 |
| message | string | ok |
| data.claimed | bool | 本次请求是否实际发放积分（幂等场景可能为 false） |
| data.scene | string | 领取场景 |
| data.amount | int | 领取积分数 |
| data.balance | int | 领取后积分余额 |
| data.history_id | int | 积分流水 ID |

> 支持按 source_id 幂等，同一 source_id 重复请求不重复发放。

示例：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "claimed": true,
    "scene": "daily_checkin",
    "amount": 10,
    "balance": 520,
    "history_id": 42
  }
}
```

#### 错误码

| code | 说明 |
|------|------|
| 40001 | 参数校验失败（scene 字段缺失或取值无效） |
| 40100 | 未登录或 Token 已过期 |
| 50000 | 服务器内部错误 |

#### 示例

```bash
curl -X POST "https://api.example.com/api/points/claim" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..." \
  -H "Content-Type: application/json" \
  -d '{"scene": "daily_checkin"}'
```

### POST /api/points/redeem — 积分兑换

#### 请求头

| Header | 值 | 必填 | 说明 |
|--------|------|------|------|
| Authorization | Bearer \<jwt_token\> | 是 | 登录后获取的 Token |
| Content-Type | application/json | 是 | |

#### 路径参数

无

#### 查询参数

无

#### 请求体

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| redeem_type | string | 是 | — | 兑换类型：`exam_discount` / `course` |
| amount | int | 是 | — | 消耗积分数，必须大于 0 |
| target_id | int\|null | 否 | null | 兑换目标 ID（如考试或课程 ID） |
| description | string\|null | 否 | null | 兑换说明 |

示例：

```json
{
  "redeem_type": "exam_discount",
  "amount": 50,
  "target_id": 1,
  "description": "H3C-NE 考试折扣"
}
```

#### 响应体

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 |
| message | string | ok |
| data.redeem_type | string | 兑换类型 |
| data.amount | int | 消耗积分数 |
| data.balance | int | 兑换后积分余额 |
| data.history_id | int | 积分流水 ID |

> 余额不足时拒绝，并发场景下原子扣减不透支。

示例：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "redeem_type": "exam_discount",
    "amount": 50,
    "balance": 470,
    "history_id": 43
  }
}
```

#### 错误码

| code | 说明 |
|------|------|
| 40001 | 参数校验失败（redeem_type 取值无效或 amount 非正数） |
| 40100 | 未登录或 Token 已过期 |
| 40200 | 积分余额不足 |
| 50000 | 服务器内部错误 |

#### 示例

```bash
curl -X POST "https://api.example.com/api/points/redeem" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..." \
  -H "Content-Type: application/json" \
  -d '{"redeem_type": "exam_discount", "amount": 50, "target_id": 1}'
```
